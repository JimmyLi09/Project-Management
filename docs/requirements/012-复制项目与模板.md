# 需求：复制项目 / 模板导入导出 + Checklist 拖动排序

- **需求编号**：REQ-012
- **标题**：Copy 整项目/仅排期/仅清单 + Import + Save as Template + Checklist 拖动
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-08-06
- **优先级**：P1 · 对应 0806 建议 #4 #4.1

## 1. 背景
开新项目常照抄类似项目，现只能手动重建；也不能把常用清单/排期存成模板复用；Checklist 顺序调不了。

## 2. 目标
支持 Copy Entire Project / Copy Schedule Only / Copy Checklist Only；提供 Import 与 Save as Template（可导入/导出现有模板）；Checklist 项可拖动排序。

## 3. 范围
**做：** 三档复制；模板保存/导入/导出；Checklist 拖动排序并持久化。
**不做：** 不做跨账号模板市场。

## 5. 验收标准
- [ ] Copy 三档均可生成对应内容的新项目/片段。
- [ ] 可把当前 Schedule/Checklist 存成模板，并在新项目导入。
- [ ] Checklist 项可拖动调整顺序，保存后保持。

## 7. 备注
模板结构对齐 REQ-018 / REQ-019 的参考模板。
