## 1. 现状（查代码确认）

1. **步骤条在 05 / 06 / 07 被隐藏**：`AvSteps.tsx` 的 `SHELLED = ['avhome','avconfig','avcostquote','avlibrary']` 在这些页面 `return null`（0929 改版时认为「合并页自带标签，再叠步骤条太满」）。结果只有 01、02–04 有步骤条。
2. **没有后退**：切页只改 store 里的 `view`，不改网址，浏览器后退键直接离开平台；页面里也没有「上一步」。
3. **页面标题显示「总览」**：`App.tsx` 的 `PAGE_META` 没有 `avhome / avconfig / avcostquote / avlibrary`，这四页顶部都显示「总览 · 项目组合健康度…」。
4. **按钮指错**：06 成本核算空状态「该项目这条业务线还没有保存的 05 方案」，LED 的按钮却是「去 02–04 图纸校核」（`AvCostView.tsx`），应去 05。
5. **数据不自动往下走**：04 全部确认后，05 要手点「从图纸导入（03/04）」；05 不点「保存方案到项目」，06 就说没有方案。
6. **每页重新选项目**：02、06 各有自己的项目下拉；05 顶部还有一个含义不清的「合并总览 ›」。

## 2. 决定（0930 已确认）

- **左侧栏 AV 分组保留现在 6 项**（AV 工作台 / 立项询价 / 图纸校核 / 方案配置 / 成本与报价 / 资料库），不改结构；同时**每一步的页面都恢复顶部 01→07 步骤条**。
- 05 点「下一步：06 成本核算」时**弹窗确认后自动保存为正式版本**并进入 06。

## 3. 功能说明

### 3.1 流程顶栏（01、02–04、05、06、07 每页都有；AV 工作台、资料库不显示）

从上到下：

1. **「‹ 返回 AV 工作台」** + **当前项目选择**（整个流程只在这里选一次，选中后五步共用；各页原来的项目下拉删除或与之联动）+ 「最近更新：今天 19:40 · PD」。
2. **01→07 步骤条**，每一步显示状态：
   - ✓ 已完成（绿）、当前（深色底）、待做、草稿 · 未保存正式版、🔒 锁定（悬停说明原因，如「报价要先完成 06 成本核算」）。
   - 状态与 AV 工作台同一套判定（`api/av/overview` 的阶段逻辑抽成共用函数，按项目取）。
   - 点任一未锁定的步骤直接跳过去，项目保持不变；05 进入时落在上次的业务线标签，06 / 07 落在对应标签。
3. 05 页内的业务线标签、06 / 07 页内的「成本核算 / 报价审批」标签保留在步骤条**下方**。
4. 删除 05 顶部的「合并总览 ›」（06 已经有项目合并汇总，步骤条可直达）。

### 3.2 后退与上一步 / 下一步

- **浏览器后退 / 前进可用**：切页时把 `视图 + 标签 + 业务线 + 项目` 写进网址（`history.pushState`，如 `?v=avconfig&line=led&p=<id>`），监听 `popstate` 还原；**刷新页面停在原处**，不回总览。全站其它页面同样受益，但本期只要求 AV 流程和从 AV 进出的跳转正确。
- **底部固定操作栏**（每一步页面）：左「‹ 上一步：02–04 图纸 · 解析 · 校核」，右「下一步：06 成本核算 ›」，中间一句当前状态 / 不能前进的原因（如「还有 2 项未确认」「正式版本 v2 已保存」）。第一步没有上一步，07 没有下一步。

### 3.3 数据自动往下走

- **04 → 05**：04 全部确认后，第一次打开 05 时（该业务线还没有正式版本也没有草稿）**自动带入**校核值，字段下标「来自图纸 · 04 已确认」；原「从图纸导入（03/04）」按钮改为「重新从图纸带入」。之后 04 又有修改时，05 顶部提示「图纸校核有更新，是否重新带入？」，不自动覆盖。
- **05 → 06**：点「下一步」弹窗「把当前方案保存为正式版本 vN 并进入成本核算？」→ 确认即保存（沿用 AV-016 的草稿 / 正式版本）并跳 06；与最新正式版本没有差别时不弹窗、直接进入。没有保存权限的人，「下一步」可点但只进入查看，并提示「需 PD / BD 保存方案后才能核算」。
- **06 → 07**：成本确认后才解锁 07；「下一步」直接进入报价审批标签。
- **06 空状态修正**：「该项目这条业务线还没有保存的 05 方案」→ 按钮「去 05 方案配置 ›」（带上业务线）。

### 3.4 页面标题

`PAGE_META` 补齐：AV 工作台、方案配置、成本与报价（成本核算 / 报价审批两个副标题随标签变）、资料库（历史案例 / 价格库）；中英两套。

### 3.5 侧栏

- 6 项保留；当前所在步骤对应的侧栏项高亮（06、07 都高亮「成本与报价」）。
- 从侧栏进入某一步时，若还没有选项目，自动选「上次在做的 AV 项目」，没有就提示在顶栏选择。

## 6. 落地说明（0930 实现时的取舍）

1. **AV-016 没有随这批给到**（压缩包里只有 015、017 的文件，仓库里也没有 AV-016）。依赖它的两处按最小自洽的办法做了，等 AV-016 到了再对齐：
   - 「正式版本 vN」= 这个项目这条业务线在 05 **保存过的第 N 次方案**（原来每次「保存方案到项目」就会存一版，只是没编号）。
   - 「草稿」：见第 7 节（AV-016 三条随后先行实现）。
2. **按原型 v1_2**：顶栏除了「返回 AV 工作台」还有一个「‹ 后退」按钮（和浏览器后退键同一件事；进平台的第一页时置灰）。
3. **05 打开载入最新正式版本**：原来 05 每次都是出厂默认值，存过的方案看不到 —— 这是「05 不存 06 就没方案」之外的另一半不顺。现在打开就是上次存的；没存过、且 04 有校核完的图纸，就自动带入（标「来自图纸 · 04 已确认」，图片判读来的标「来自图片 · 已人工确认」）；04 之后又有新校核结果时，顶部提示「图纸校核有更新，是否重新带入？」，不自动覆盖。
4. **05 →「下一步」**：和最新正式版本比较（箱体库等于参数组默认值时视为未改），有改动才弹窗；排布无解时不弹窗、底部写原因；没有保存权限（不是这个项目的 PM，也不是 PD / BD）时照常进入 06 查看，并提示「需项目 PM 或 PD / BD 保存方案后才能核算」—— 实际能存方案的是项目 PM 与 PD / BD（与原权限一致），不只 PD / BD。
5. **步骤状态**（`server/avflow.ts`，工作台 `api/av/overview` 共用）：01 有立项记录或有 AV 业务线即完成；02–04 没有 LED 线时显示「本项目不用」；06 以「每条线的最新成本单已确认、且对应最新方案」为完成；07 在成本未全部确认前锁定，PM 看不到报价所以 07 对 PM 锁定并写明原因。工作台的阶段口径没变。
6. **网址**：`?v=<页面>&s=<标签>&line=<业务线>&p=<AV 项目>`（项目页另带 `pid / tab / pkg`，统计下钻带 `f`）；换项目只替换当前网址，不往后退历史里塞一条。0929 之前的单页入口（LED 方案配置、AV 成本核算等）一律落到合并页的对应标签上。
7. **一次选项目**：02、06、07 与投影 / 弱电 / 光伏 05 自己的项目下拉都删了；顶栏只列看得见的、有 AV 业务线的项目（REQ-043 不变）；记住上次在做的项目，从侧栏进来直接用它。06 选中的项目没有当前业务线时，自动换到它有的第一条线。

## 7. AV-016 三条的先行实现（0930 · AV-016 文档到了再对齐）

> 1001 更新：AV-016 文档已到（#67），已按文档补齐（#68），以 AV-016 文档 §6 为准；下面是 0930 先行时的记录。

AV-016 的需求文档没有随这批给到，Jimmy 0930 定「先按 AV-017 里提到的三条做，文档后补」：

1. **图纸先留档再解析**：上传的原件先存进 `data/av-files/<留档号>/`（表 `av_upload`），再解析。解析失败的留档照样列在「项目图纸」里（红底，写失败原因），可以**重新解析**（矢量 PDF 可当场补比例尺）、**下载原件**；解析成功的图纸 / 图片判读行也有「原件」下载。步骤条 02–04 有失败留档时显示「N 份解析失败，原件已留档」。删除项目时留档一并删除。
2. **05 自动保存草稿**：每个项目每条业务线一份草稿（表 `av_config_draft`，谁改都存在同一份里，记最后改的人和时间）。停手约 1.2 秒自动存，页面显示「✓ 草稿已自动保存 · 19:40」；只是打开看不会产生草稿；和正式版本一样时自动删掉。重开 05 **草稿优先**载入（「已载入草稿（谁 · 何时），还没存成正式版本」），可「丢弃草稿，回到正式版本 vN」。存成正式版本（手动保存或「下一步」弹窗）时草稿清掉。**草稿不进 06**，成本只按正式版本算。只有能存方案的人（项目 PM、PD / BD）才会自动存草稿。步骤条 05 有草稿时显示「草稿 · 未保存正式版」；04 → 05 自动带入的条件改为「没有正式版本、也没有草稿」。
3. **工作台 5 个数字 + 进度条**：五个数字 = 五个阶段各有几个进行中的项目（立项中 / 待图纸校核 / 待方案配置 / 待成本核算 / 待报价 · 审批；看不到价格的角色没有后两格），点一下下面的表只看那一个阶段，再点取消。原来的「价格已过期物料」改成数字下方一行提示（带「去价格库」）。每个项目的「阶段」下多一条 01→07 五格进度条，颜色与步骤条同一份状态，悬停看每一步。
