## REQ-012 复制项目 / 模板 —— 增：含内容复制 + 分步向导 + 页内弹窗
- **含内容复制**：套用模板 / 复制时提供开关「连内容一起复制」（状态 / 日期 / 服务器路径 / 参考图）。现状只复制结构（内容空），需支持连内容复制；可选复制哪些分区。
- **复制后分步向导**：选择来源 → 选择复制范围 → 预览（几分区 / 几项 / 含内容几项）→ 完成（可继续编辑 / 再存模板）。
- **存为模板改页内弹窗**：替代浏览器原生 `prompt()`（录屏中为原生框）；页内弹窗输入模板名，并可勾「同时保存当前内容」。
- 验收：套用后内容按开关带入 / 或为空；存模板不再弹浏览器原生框；向导四步可走通。

## REQ-039 Job Record —— 增：全字段自动计算 + list + 下载 + 去固定块
- **可下载** Job Record（PDF / Excel）。
- **去掉固定只读块**（原「项目信息 · 同步自项目创建(只读)」条，Progress 图4）。
- **业务整体选择 + 完整 list**：业务用一个完整下拉（CGI / ANIMATION / SCALE MODEL / WEBSITE / MATTERPORT / 3D VR / LED / PROJECTOR / SALESKIT / DRONE / MAXHUB / LIGHTBOX / AV / BROCHURE / INTERIOR DESIGN / RENOVATION / OTHERS，Progress 图5），选完加入列表，可多块。
- **LED 全字段自动计算**（Progress 图6 + Calculator reference）：
  - SQM 面积 = L × H / 1,000,000
  - 数量 Total = 数量L × 数量H
  - DB Box (KW) = SQM × 450 / 1000（= Max KW）
  - 散热 = DB × 0.5 × 0.8
  - Power Cable / Data Cable = 手填（参考表无公式，**待确认**是否有规则）
  - 字段：L, H, SQM, 数量L, 数量H, 数量Total, Type, DB Box(KW), Power Cable, Data Cable, Speaker, Remarks
- **编辑 + 粗体高亮**：一个「编辑」按钮改额外业务信息，关键项粗体高亮。
- 验收：可下载；无固定只读块；业务下拉全量 + 可多块；LED 上述字段随尺寸自动算、数值与 Calculator reference 一致（10560×3200 → SQM 33.792 / DB 15.21 / 散热 6.08）。
