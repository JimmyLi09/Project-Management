# 需求：导出版式优化

- **需求编号**：REQ-017
- **标题**：编号重排 / 列宽统一 / 分页 / 页码 / 页眉页脚 / 换行 / A4 横纵
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-08-06
- **优先级**：P2 · 对应 0806 建议 #9 #10

## 1. 背景
导出能用但排版有细节问题：删 Section 后编号不重排、列宽不一、内容贴边、超一页只导第一页、无页码/页眉页脚、长文不换行、表格中间断页。

## 2. 目标
统一修复上述版式问题，并支持 A4 横向/纵向选择。

## 3. 范围
**做：** 删 Section 编号自动重排；列宽统一；保留页边距；多页自动分页；页码；页眉/页脚；长文自动换行；表格尽量不中间断页；A4 横/纵选择。
**不做：** 不做任意自定义模板编辑器。

## 5. 验收标准
- [ ] 删除某 Section 后其余编号连续。
- [ ] 内容超一页时完整分页导出（非只第一页），带页码。
- [ ] 有页眉/页脚；长文换行；列宽一致；A4 横/纵可切换。

见效果图「导出」页 ③ 版式。
