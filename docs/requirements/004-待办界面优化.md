# 需求：我的待办界面优化

- **需求编号**：REQ-004
- **标题**：待办隐藏未开始 + 勾选/Year/项目编号 + 右侧项目信息与追踪
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-08-05
- **优先级**：P1（含 Bug #11）· 对应优化点 #11 #15 #7 + 新增

## 1. 背景
未开始的项目混进待办（#11，应隐藏）；需右侧按项目显示对应信息（#15）；每条可点击追踪到详情（#7）；并需新增勾选完成、Year 列、项目编号。

## 2. 目标
待办只显示已开始任务；支持勾选完成；有 Year 列可按年筛选；项目名带编号；点任务在右侧显示该项目信息并可打开详情。

## 3. 范围
**做：** 过滤未开始；行首勾选框（勾=完成，划线/归档）；新增 Year 列与按年筛选；项目名带编号（如 020-Lentor Mansion）；点行→右侧项目信息面板 + 打开项目详情按钮。
**不做：** 不改待办生成规则本身（除“未开始不进待办”）。

## 5. 验收标准
- [ ] 状态为“未开始”的项目任务不出现在待办列表（#11）。
- [ ] 每行有勾选框，勾选后标记完成。
- [ ] 列表含 Year 列，可按年份筛选。
- [ ] 项目名带编号前缀。
- [ ] 点击任一待办，右侧显示对应项目信息，并可跳转项目详情（#15/#7）。

## 7. 备注
参见可交互原型「我的待办」页。
