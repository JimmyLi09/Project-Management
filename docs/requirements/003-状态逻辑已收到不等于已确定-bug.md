# 需求：信息状态「已收到 ≠ 已确定」，避免误报逾期（Bug 修复）

- **需求编号**：REQ-003
- **标题**：修正信息项状态逻辑与逾期判定
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-08-05
- **优先级**：P0（Bug）· 对应优化点 #10

## 1. 背景
选择「已收到」时上方却出现「逾期」——把“已收到”误当成“该确认还没确认”。已收到与已确定是两种状态，不应等同。

## 2. 目标
「已收到」=资料到位、正常，不触发逾期；「已确定」=最终确认；只有“未收到且已过期”才标逾期。

## 3. 范围
**做：** 明确状态机 未收到/已收到/已确定；逾期只由“未收到且过截止”触发；修正相关展示。
**不做：** 不新增额外状态。

## 5. 验收标准
- [ ] 将某信息项设为「已收到」，上方不再出现逾期标记。
- [ ] 设为「已确定」显示完成态。
- [ ] 仅当状态=未收到且已过截止日时，才显示逾期。

## 7. 备注
纯状态判定逻辑修正，服务端与前端展示一致。
