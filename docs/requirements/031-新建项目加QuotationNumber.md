# 需求：新建项目增加 Quotation Number 字段

- **需求编号**：REQ-031
- **标题**：新建项目表单增加「Quotation Number（报价单号）」栏
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-09-02
- **优先级**：P2 · 0902 批次

## 1. 背景
新建项目时目前只有项目名称，没有地方填报价单号。业务上每个项目通常对应一个 Quotation Number，需要在建项目时就记录、方便日后对账 / 检索（图3 红框处，在项目名称旁）。

## 2. 目标
在「新建项目」表单增加一个「Quotation Number」字段，位置在项目名称旁 / 同一行区域；填写后随项目保存，并在项目详情可见。

## 3. 范围
**做：**
- 新建项目表单增加字段「Quotation Number」（报价单号），位置参照图3：项目名称右侧同一区域。
- 该字段保存进项目数据；项目详情页可展示（放在项目名 / 客户信息附近的合适位置）。
- 项目详情编辑时可修改该字段。

**不做：** 本期不做报价单号唯一性校验、不做与外部报价系统对接、不做按报价号的高级检索（能作为普通信息展示即可；如需检索另提）。

## 5. 验收标准
- [ ] 新建项目表单出现「Quotation Number」字段，位置在项目名称旁。
- [ ] 填写后保存，项目详情能看到该报价号。
- [ ] 项目详情可编辑该字段并保存。
- [ ] 不填也能正常建项目（默认非必填；如需必填请指出）。
- [ ] 老项目无此字段时正常显示为空 / 占位，不报错。

## 7. 备注（含默认假设，如需调整请在 PR 指出）
- 默认「非必填」；若报价号应强制填写，请指出改为必填 + 校验。
- 默认为纯文本（可含字母数字与短横线，如 Q-2026-0123）；是否需要格式校验请指出。
- 与已上线的 **REQ-010**（新建表单增删分区与公司联系人）同处新建表单，仅新增字段，不改其分区逻辑。
- 是否要让全局搜索框也能按报价号搜，本期未含，如需要另提一条。
