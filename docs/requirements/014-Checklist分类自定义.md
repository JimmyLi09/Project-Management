# 需求：Checklist 分类可自定义

- **需求编号**：REQ-014
- **标题**：分类支持新增/改名/删除，或无固定分类模式
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-08-06
- **优先级**：P1 · 对应 0806 建议 #6

## 1. 背景
分类现固定为 Architect / ID / Sales，但不同项目分工不同，同一资料不一定每次同一方提供，固定分类别扭。

## 2. 目标
分类可新增/改名/删除；也可切「无固定分类」模式，仅保留 Item / Status / Date received / Remarks。

## 3. 范围
**做：** 分类 CRUD；无固定分类开关；导出随所选模式。
**不做：** 不强制迁移历史数据分类（保留原值）。

## 5. 验收标准
- [ ] 可新增、重命名、删除分类。
- [ ] 开「无固定分类」后清单仅四列显示与导出。
- [ ] 分类变更持久化且反映在导出。

## 7. 备注
现平台为写死的 建筑方/ID/Sales，本条改为可维护。
