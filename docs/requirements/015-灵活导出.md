# 需求：灵活导出 — 选内容 + 自由排序 + 统一表单

- **需求编号**：REQ-015
- **标题**：自选导出内容与顺序，所有表单统一模板
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-08-06
- **优先级**：P1 · 对应 0806 建议 #7 #10

## 1. 背景
一按导出就是固定整套、顺序写死；不同客户/用途出不同版本做不到；多份表单格式不统一。

## 2. 目标
可勾选导出内容（Animation / VR / Brochure / Schedule Only / Checklist Only / Schedule+Checklist）；可调整排列（按项目穿插 / 所有 Schedule 集中 / 所有 Checklist 集中）；所有表单统一模板。

## 3. 范围
**做：** 内容多选 + 顺序选择 + 统一模板导出。
**不做：** 不做任意自由拖拽排版（提供预设排列即可）。

## 5. 验收标准
- [ ] 可勾选任意内容子集导出。
- [ ] 可切换三种排列方式，导出结果符合所选顺序。
- [ ] 多份表单使用统一模板样式。

## 7. 备注
与 REQ-016（公司说明）、REQ-017（版式）配合。
