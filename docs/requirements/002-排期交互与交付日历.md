# 需求：排期直接拖动 + 交付日历并排 + 时间关联

- **需求编号**：REQ-002
- **标题**：排期拖动/自定义标注 + 交付日历并排且时间关联
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-08-05
- **优先级**：P1 · 对应优化点 #9 #8 #8b #12 #21

## 1. 背景
排期需先点“编辑”才能拖动，操作繁琐（#9）；缺交付日历视图（#12）；日历与排期未联动（#21）；不同项目交付时间应以最后阶段为准（#8）；需临时插入小样/额外需求（#8b）。

## 2. 目标
排期支持直接拖动排序；同页右侧显示交付日历，且与排期周期时间关联（改周期→日历色块跨度联动）；可自定义添加标注节点；项目交付日=最后阶段结束。

## 3. 范围
**做：** 拖动排序（无需先点编辑）；交付日历与排期并排同页；日历按阶段周期渲染日期跨度并联动；自定义标注节点（名称/日期/负责人，custom 标记）；交付日取最后阶段结束。日历时间点/阶段颜色区分（交付/冻结点/客户审阅/逾期）。
**不做：** 不做完整日历引擎；不引入外部日历库。

## 4. 详细需求
作为 PM，我想拖着排序、并在同页日历看到各阶段落在哪些日期，以便直观规划与临时插入小样。

## 5. 验收标准
- [ ] 不点“编辑”即可拖动阶段排序，松手即保存新顺序。
- [ ] 排期与交付日历在同一页并排显示。
- [ ] 修改任一阶段周期，日历上对应阶段色块跨度即时变化（时间关联）。
- [ ] 可新增自定义标注节点并显示为区分样式。
- [ ] 项目交付日 = 最后阶段结束日（多阶段以最后时间为准）。

## 6. 边界与异常
拖动到非法位置回弹；日历跨月时按实际日期展开。

## 7. 备注
参见可交互原型「排期 + 交付日历」页。
