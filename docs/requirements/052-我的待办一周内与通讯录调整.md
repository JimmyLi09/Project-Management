  - 侧栏数字 `myOpenCount`（`App.tsx:167-180`）**没排除已归档和售前项目**，会比列表多。
- **通讯录**（`ContactsView.tsx:116-117`）：
  - 列顺序是 项目 / 角色 / 公司 / 联系人 / 电话 / 邮箱；

## 2. 功能说明

### 2.1 我的待办（第 8 条）
- 只显示两组：
  - **已逾期**：结束日期早于今天且未完成，标「逾期 N 天」；
  - **本周内**：今天到今天 + 7 天。
- 一周以后的任务**不显示**，到时间自然出现；要看可以去项目排期。
- 原来的「全部 / 进行中」筛选和年份筛选去掉，只保留按项目搜索。
- 侧栏数字 = 逾期 + 本周内，并和列表用同一个函数计算（顺便修掉没排除归档 / 售前的问题）。
- 工作流待办（交接、完工、开票等）和 AV 保修提醒同样按这个时间范围过滤。

### 2.2 通讯录（第 9、10 条 + 年份）
- 列顺序改为：公司 / 联系人 / 电话 / 邮箱 / **年份** / 项目编号 / 角色。CSV 导出同顺序。
- **年份** = 项目立项年份：优先从项目编号推断（若编号带年份），否则取 `p.created` 的年份。顶部加年份筛选（全部 / 2026 / 2025…）。
- **角色「客户」改名为「Developer / 发展商」**：
  - 角色下拉（`ProjectDetail.tsx:1237-1244 CONTACT_ROLES`）、显示词表（`terms.ts`）、兜底行都改；
  - 已存的 `'客户 Client'` 上线时一次性改为 `'发展商 Developer'`，中文界面显示「发展商」，英文界面显示「Developer」；
  - 同时把 `'总包 Main Con'` / `'总包 Main-con'` 统一成一个值。
- 角色改为存**键**（`developer` / `maincon` / `architect`…），显示时再翻译。自定义的「其他（手填）」仍存文本。

- **我的待办**
