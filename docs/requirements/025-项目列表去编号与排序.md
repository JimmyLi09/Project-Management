# 需求：项目列表去掉系统编号前缀 + 可选排序方式

- **需求编号**：REQ-025
- **标题**：项目列表移除左侧系统编号 + 排序方式可切换
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-08-11
- **优先级**：P2 · 0811 批次

## 1. 背景
项目列表（列表视图）每行最左侧有系统自动序号（014 / 013 / 012 …），显得冗余、也和项目名本身的编号（如 128- / 123-59）混淆。另外列表目前是固定排序，用户希望能按不同维度排。

## 2. 目标
① 列表视图去掉左侧的系统编号前缀，只显示项目名（项目名内本身的数字如「128-C&K T1 LED」保留不动）。
② 排序改为 **点列头**（Excel 式）：默认按项目编号，点任一列头即按该列排序，再点切换升 / 降序。**不做独立的排序选择器**。

## 3. 范围
**做：**
- 列表视图移除最左侧系统序号（014 等）的显示；项目名整段保留。
- 排序（Excel 式列头排序）：列表主表头的各列头（项目 / 服务 / PM / 阶段 / 交付日期 / 健康）可点击排序；点一次按该列升序、再点降序，列头显示当前排序方向（↑ / ↓）箭头；同一时刻按单列排序。
- 默认排序：按项目编号（系统内部序号，即当前默认顺序），未点任何列头时保持该默认序。
- 若「大卡片」视图也带同样的系统编号前缀，一并去掉。

**不做：** 不再做独立排序下拉 / 按钮；不改项目名本身内容；不删除数据里的系统编号（只是列表不显示，详情页 / 接口仍可用）；不做多列组合排序。

## 5. 验收标准
- [ ] 列表视图左侧不再显示系统编号（014 等），项目名完整显示。
- [ ] 列表默认按项目编号排序（与原默认顺序一致）。
- [ ] 点 项目 / 服务 / PM / 阶段 / 交付日期 / 健康 任一列头即按该列排序；再点切换升 / 降序；列头有当前排序方向指示。
- [ ] 没有独立的排序选择器控件（排序入口就是列头）。
- [ ] 大卡片视图若原有该前缀，也已去掉。

## 7. 备注（含默认假设，如需调整请在 PR 指出）
- 「项目编号」默认指系统内部序号（原 014… 那个）作为默认排序键 —— 列表虽不显示它，仍按它排默认序。若你指的是项目名里的编号（128-），请指出。
- 系统编号只是隐藏显示，数据保留，不影响详情页 / 接口 / 其它页面。
- 排序状态是否跨刷新记住，按现有实现即可（会话内生效为底线）。
