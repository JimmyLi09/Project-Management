## 1. 价格库（侧栏「AV 价格库」）

- 表 `av_price_item`，初始为空；PD / BD 点「导入 2026 LED 价格表（PDF）」载入
  《Audax LED Cost Book (2026 April)》（文件 `Audax_LED_Price_List-2026_June.pdf`）的 **8 类 47 条**。
  数据在 `src/av/data/led-price-2026-04.json`，94 个价格已与 PDF 原文逐一比对一致。重复导入不会重复。
- 列：类别、型号、点间距、模组尺寸、箱体 / 产品尺寸、单位、**成本价（取 Partner Price）**、**售价（取 MSRP）**、
  有效期至、启用状态、来源、更新人 / 时间。价格可留空表示「待定价」。
- **价格会变**：每次改价或改有效期都写入 `av_price_history`，可在每行「历史」查看。
- 公司参数：**毛利下限**（`av_setting`），默认 18%（取自 06 原型）。
- 权限：PD / BD 编辑；销售、PM、Finance 可查看；成员与只读角色看不到成本价。
- PDF 中没有的线材、控制系统、钢结构、安装人工等需逐条添加。

### 源数据注意
- PDF 表头为「2026 April」，文件名为「2026 June」，来源字段两者都记。
- 高端全息屏 U6 型号标 P6.25，点间距列却为 6.66 mm；M3 型号标 P3.91，点间距列为 3.9 mm。原样导入，待确认。
- MSRP 普遍为 Partner Price × 1.2（高端全息屏 × 1.15），即按此两列计算的毛利约 16.7%（高端全息屏约 13%），
  **低于默认下限 18%**。如 Partner Price 并非公司成本价，请在价格库中改为实际成本。

## 2. 05 方案存档（§10 config_result）

- 05 从已校核图纸载入后出现「保存方案到项目」（该项目 PM / PD / BD）。
- **服务端用同一套计算内核重算**：规则包取立项绑定的版本，已校核图纸的数值覆盖表单中对应字段；
  排布无解拒绝保存。每次保存一条记录（`av_config`），并写项目操作记录。

## 3. 06 LED 单线成本（侧栏「AV 成本核算」，流程条 06）

| 行 | 数量依据 |
| --- | --- |
| LED 显示屏 | F1 面积（㎡，两位小数） |
| 电源线（含 1 备用） | F7 |
| 数据线（含 1 备用） | F9 |
| 附加项 | 人工填写名称、数量、单位（控制系统、钢结构、安装人工…） |

- 每行从价格库选条目；显示屏候选按点间距匹配排前，按台计价的海报不在显示屏候选中。
- **成本表保存时快照单价**（`av_cost_sheet`），之后价格库改价不影响已存的表，检查中提示「可重算」。
- **提交前检查**：未选条目、缺价、单位不符、方案有阻断项（如待校准参数组 LED-TYPE-01）→ 阻断确认；
  价格已变动、价格过期、条目已停用、毛利低于下限 → 提示。
- 「保存草稿」「确认成本」；确认写项目操作记录。05 方案重新保存后，旧成本表标「需重算」。
- **项目合并汇总**：按项目立项时的业务线列出成本、售价、毛利、状态与合计。跨业务线去重在第二条业务线接入后启用。
