# 需求：总览 KPI 数字可点击下钻

- **需求编号**：REQ-011
- **标题**：总览「进行中/按期率/未解决风险」可点击查看明细
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-08-06
- **优先级**：P2 · 对应 0806 建议 #3

## 1. 背景
总览 KPI 只是数字，看到「未解决风险 13」却点不进去，不知具体是哪些。

## 2. 目标
每个 KPI 可点击展开对应明细列表，点条目跳进对应项目/待办。

## 3. 范围
**做：** 进行中项目、按期率、未解决风险三卡可点击 → 明细弹层/面板 → 条目可跳转。
**不做：** 不新增统计口径。

## 5. 验收标准
- [ ] 点「未解决风险」展开对应风险项列表。
- [ ] 点列表任一条进入对应项目详情。
- [ ] 其余两卡同样可下钻。
