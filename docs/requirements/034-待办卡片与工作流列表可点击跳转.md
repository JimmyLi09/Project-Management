# 需求：我的待办卡片 + 两页「需要我处理」列表项可点击跳转（补 REQ-011 未覆盖部分）

- **需求编号**：REQ-034
- **标题**：我的待办顶部卡片与「需要我处理」列表项可点击直达项目
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-09-02
- **优先级**：P2 · 0902 批次

## 1. 背景
用户在总览页与我的待办页都圈注：顶部统计卡片、以及「需要我处理（工作流）」列表的每一条，点了都要能直达对应项目（图9 我的待办、图10 总览）。
其中**总览的三张 KPI 卡（进行中项目 / 按期率 / 未解决风险）可点击下钻**已由已上线的 **REQ-011** 覆盖。本条只补 REQ-011 **没覆盖**的部分，避免重复。

## 2. 目标
① 「我的待办」页顶部卡片（未完成任务 / 逾期）可点击，跳到对应筛选后的待办列表。
② 总览页与我的待办页的「需要我处理（工作流）」列表，每一条项目行可直接点击 → 跳到该项目详情。

## 3. 范围
**做：**
- **我的待办·顶部卡片**：
  - 「未完成任务」卡 → 点击定位到全部未完成列表；
  - 「逾期」卡 → 点击定位到逾期列表；
  - 与页面已有的「全部 / 逾期 / 进行中」筛选联动一致。
- **「需要我处理（工作流）」列表项**（总览页 + 我的待办页都有这个区块）：每条（如 092-Canon Adastra Machines）整行可点击 → 跳该项目详情（尽量定位到相关工作流 / 待办位置）。
- 可点击区域要有可点提示（hover 手型 / 高亮）。

**不做：**
- **不重复做**总览三张 KPI 卡（进行中 / 按期率 / 未解决风险）的下钻 —— 那是已上线的 **REQ-011**，本条不动它（若 REQ-011 上线后表现 OK，此部分自然满足）。
- 不改统计口径；不做新的中间弹层（能直接跳转就直接跳）。

## 5. 验收标准
- [ ] 我的待办「未完成任务」「逾期」两张卡可点击，分别跳到对应筛选列表（与现有筛选一致）。
- [ ] 总览页与我的待办页的「需要我处理」列表，每条可点击跳到对应项目详情。
- [ ] 可点元素有 hover 手型 / 视觉可点提示。
- [ ] 跳转后能对上（点某条工作流落到的确实是该项目）。
- [ ] 不与 REQ-011 冲突：总览三卡的下钻仍按 REQ-011 行为。

- 明确与 **REQ-011**（总览 KPI 下钻）划清边界：总览三卡归 REQ-011；本条只做「我的待办」卡片 + 两页「需要我处理」列表项。
- 列表项默认跳「项目详情」；若你更想让它落到该项目的「待办 / 工作流」具体条目，请指出。
- 若实现时发现「需要我处理」列表项其实已经可点（属 REQ-011 顺带实现），本条对应部分即视为已满足，只补「我的待办卡片」即可。
