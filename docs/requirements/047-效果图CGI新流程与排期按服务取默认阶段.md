### 2.2 排期日历按服务取默认阶段
- 日历的默认阶段改为**按服务包的服务取**：CGI 用 2.1 这套；动画 / 无人机 / 沙盘 / VR 等用各自 `TPL.<svc>` 的排期步骤；没有专门模板的用通用模板（`GENERIC`）。
- PD / BD 在模板管理里改了某服务的排期步骤，**日历默认阶段同步使用**（经典排期和日历用同一份来源）。
- 「恢复默认阶段」= 恢复成该服务当前的模板阶段。

### 2.3 已有项目
- **不自动改**已有项目的排期（避免打乱进行中的计划）。
- 已有 CGI 项目在排期页顶部提示一次：「效果图流程已更新（白膜小样 → AI 效果图 → 后期图），要换成新阶段吗？」→「换成新阶段」（已排好的日期按新阶段重新分配，可撤销）或「保持不变」（不再提示）。

### 2.4 动画流程
- 本期**不改**动画（`TPL.ani`），等 Jimmy 给出动画的新流程后另开需求。

## 4. 落地说明（#75）
- **CGI 模板**：`TPL.cgi` 换成表中 5 步，中英文名、默认周数、节点都按表填。原来的「搭建 3D 建筑模型」并入白膜一步。
- **日历默认阶段**：取自这项服务**当前生效**的模板（PD / BD 改过就用改过的），一步一个阶段，名称取任务名（中 / 英），默认工期取周数。没有专门模板的服务用通用模板。新增只读接口 `/api/templates/stages?svc=`，登录即可取（模板管理接口只给 PD / BD）。
- **注意**：如果服务器上 PD / BD 以前在模板管理里改过 CGI 模板，生效的是那份改过的老模板，新流程不会出现。要用新流程，在模板管理里对 CGI 点「恢复默认」。
- **已有项目**：
  - 经典排期和日历排期都不自动改。
  - 认「老流程」的办法：日历排期里存的正好是 REQ-047 之前那 6 个阶段（按阶段 id 认，改过名也认得）。只有这种 CGI 排期才提示，而且只对能编辑的人显示。
  - 「换成新阶段」：首日和末日不变，按新阶段的默认周数重新分配（勾 Exclude Holidays 时按工作日）。原来的阶段和日期留着，可「撤销」；再保存一次之后就不能撤销了。
  - 「保持不变」之后不再提示。换、撤销、保持都写进项目日志。
  - 还没排过日历的 CGI 项目，打开就是新阶段，不提示。
- **经典排期**：已有项目的经典排期行不提示也不换。经典排期的阶段行连着进度统计、KPI 和导出，换掉会打乱进行中的状态。新建项目自动用新模板。
