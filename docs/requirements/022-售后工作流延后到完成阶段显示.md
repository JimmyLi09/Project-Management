# 需求：售后工作流仅在项目进入「完成」阶段后显示

- **需求编号**：REQ-022
- **标题**：售后工作流延后显示（进入「完成」阶段后才出现）
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-08-11
- **优先级**：P2 · 0811 批次

## 1. 背景
项目详情页「概览」里的「售后工作流」（交接 / 完成包 / PD 审批 / Sales 核对 / 开票 / 收款）目前从项目一进入「交接PM」阶段就整块显示。这套流程本质是项目做完之后的交付 / 开票 / 收款环节，过早出现会让 PM、Sales 在项目还没完成时就看到一堆售后步骤，容易误操作，界面也显得杂乱。

## 2. 目标
「售后工作流」只在项目推进到「完成」阶段（主阶段第 4 步）及之后才显示；在「售前 / 交接PM / 进行中」三个阶段一律隐藏。

## 3. 范围
**做：** 概览页「售后工作流」卡片按项目当前主阶段条件渲染 —— 阶段 < 完成 时隐藏，阶段 ≥ 完成 时显示；隐藏时该卡片不占位、不留空白。
**不做：** 不改售后工作流内部的步骤逻辑与数据结构；不改项目主阶段的流转规则本身。

## 5. 验收标准
- [ ] 项目处于「售前 / 交接PM / 进行中」时，概览页不显示「售后工作流」卡片。
- [ ] 项目推进到「完成」阶段后，「售后工作流」卡片出现。
- [ ] 「开票/收尾」阶段（完成之后的阶段）同样显示。
- [ ] 隐藏时不留空白占位；已有售后数据的老项目在「完成」及之后阶段仍正常显示，数据不丢。

## 7. 备注
触发以项目主阶段 stepper 的「完成」为准（第 4 阶段）。阶段模型：售前 → 交接PM → 进行中 → 完成 → 开票/收尾。仅调整「概览」页该卡片的显示条件，不影响其它页签。
