# 需求：导出 PDF 增加封面页

- **需求编号**：REQ-021
- **标题**：导出 PDF 可带项目封面页
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-08-09
- **优先级**：P2 · 0809 批次

## 1. 背景
现在导出 PDF 直接是内容页，缺一个正式的封面。给客户/内部存档时，希望第一页是项目封面，一眼能看到是哪个项目。

## 2. 目标
导出 PDF 时在最前面加一页封面，包含项目编号、项目名称、客户、日期四项关键信息。

## 3. 范围
**做：** PDF 导出生成封面页，含项目编号、项目名称、客户、日期；封面版式与现有导出风格（REQ-017 版式）保持一致。
**不做：** 本期不做自定义封面模板 / logo 上传 / 自定义字段，后续再议。

## 5. 验收标准
- [ ] 导出的 PDF 第一页为封面页。
- [ ] 封面页包含：项目编号、项目名称、客户、日期（导出日期或项目日期，按现有导出口径）。
- [ ] 封面样式与现有导出版式统一，无错版/溢出。
- [ ] Schedule 与 Checklist 两类导出均带封面（若两者共用导出入口）。

## 7. 备注
对齐现有导出相关需求：REQ-007（导出拆分）、REQ-015（灵活导出）、REQ-016（导出公司说明）、REQ-017（导出版式）。日期口径与现有导出保持一致。
