# 需求：项目档案（Document Store）升级为电子表格式

- **需求编号**：REQ-033
- **标题**：项目档案改成可点格子直接编辑的电子表格（类 Google Sheet）
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-09-02
- **优先级**：P2 · 0902 批次

## 1. 背景
「项目档案 · Document Store」现在是一张普通只读表（客户 / 项目 / 客户信息 / 文档 / 更新，图6），查看和维护都不方便。用户希望它像电子表格（参考其提供的 Google Sheet），能**直接点单元格就地编辑**，并具备表格常用能力（增列、筛选、排序）。

## 2. 目标
把项目档案做成**电子表格式**：单元格可点击就地编辑（inline edit），支持增删列、按列筛选 / 排序，操作手感接近 Google Sheet；编辑即保存（或就地保存），数据仍落在系统里。

## 3. 范围
**做：**
- 表格单元格支持**就地编辑**：点某个格子直接进入编辑、失焦 / 回车保存（不用跳到另一个表单页）。
- 支持**增删列**（自定义列，如客户信息细项 / 合同 / 地址 / 备注等），列可重命名。
- 支持按**列筛选**与**点列头排序**（升 / 降），与已上线的 REQ-025 的 Excel 式列头排序一致的交互。
- 保留现有列的语义：客户 / 项目 / 客户信息 / 文档数 / 更新时间等；文档数、更新时间这类系统列可保持只读。
- 就地编辑后即时持久化并刷新「更新时间」。

**不做：** 本期**不做**与那张 Google Sheet 的双向同步 / 嵌入（用户确认要的是「像电子表格、点格子直接改」的体验，不是接 Google 接口）；不做多人实时协同光标 / 单元格锁；不做公式引擎（如后续要单元格公式，另提，可参考已上线 REQ-027 的公式字段思路）。

## 5. 验收标准
- [ ] 项目档案表格的单元格可点击就地编辑，失焦 / 回车即保存，刷新后保持。
- [ ] 可增删自定义列、给列重命名。
- [ ] 可按列筛选、点列头升 / 降序排序。
- [ ] 系统列（文档数 / 更新时间）保持只读并自动更新。
- [ ] 老数据兼容：现有档案行照常显示，可就地编辑；空列不报错。

## 7. 备注（含默认假设，如需调整请在 PR 指出）
- 用户已确认：要的是「点格子直接改」的电子表格体验，**不是**跟他贴的那张 Google Sheet 做同步 / 嵌入。那张链接仅作观感参考。
- 与已上线的 **REQ-006**（项目档案登记表与编号）相关：本条是把该档案页的**呈现 / 编辑**升级为电子表格式，不改编号规则。
- 是否需要单元格级公式 / 下拉选项列，本期未含；如需要可参照 REQ-027 的字段类型（文本 / 日期 / 下拉 / 数字 / 公式）另行扩展。
