# 需求：项目删除权限

- **需求编号**：REQ-008
- **标题**：删除权限（仅 业务/PD/BD 可删，PM 只改/增）
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-08-05
- **优先级**：P1 · 对应优化点 #14

## 1. 背景
加错的项目删不掉；需按角色控制删除权限。

## 2. 目标
仅 业务(Sales)/PD/BD 可删除项目；PM 只能修改、新增，不能删除；成员/只读无删除。

## 3. 范围
**做：** 删除入口与后端校验按角色控制（前端隐藏 + 服务端强校验）。
**不做：** 不做软删除回收站（除非另提）。

## 5. 验收标准
- [ ] 以 Sales/PD/BD 登录，能看到并成功删除项目。
- [ ] 以 PM/成员登录，看不到删除入口；即使直接调接口也被服务端拒绝（403）。

## 7. 备注
服务端为最终权限来源。
