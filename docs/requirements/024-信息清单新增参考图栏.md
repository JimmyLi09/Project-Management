# 需求：信息清单新增「参考图 / Reference」栏

- **需求编号**：REQ-024
- **标题**：信息清单新增参考图栏（每条挂参考图片）
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-08-11
- **优先级**：P2 · 0811 批次

## 1. 背景
信息清单每条信息现在只能用文字描述，缺一个直观的参考图（效果图 / 图纸 / 现场照片缩略图）。加上参考图后，PM / 制作一眼能对上是什么。

## 2. 目标
信息清单新增「参考图 / Reference」栏，位于「信息项」和「负责人」之间：查看态显示只读缩略图（可点开看大图），编辑态可上传 / 更换 / 删除。

## 3. 范围
**做：**
- 新增列「参考图 Reference」，位置在 信息项 与 负责人 之间。
- 查看态：显示只读缩略图，点击弹层（lightbox）看大图；每条支持多张，平铺显示；无图显示「暂无参考图」占位。
- 编辑态（点信息清单「编辑」后）：可上传（点击选文件 / 拖入 / 粘贴）、更换、删除图片。
- 图片走信息清单现有的图片上传通道与存储。

**不做：** 不做图片在线编辑 / 标注；不做纯外链图片；不做参考图的独立权限。

## 5. 验收标准
- [ ] 信息清单在「信息项」与「负责人」之间出现「参考图」列。
- [ ] 查看态：有图显示缩略图、点击可看大图；无图显示占位；查看态不能上传 / 删除（对齐 REQ-005 只读）。
- [ ] 编辑态：可上传（选文件 / 拖入 / 粘贴）、更换、删除；每条支持多张。
- [ ] 保存并刷新后图片保持。
- [ ] 老数据兼容：原有条目无图时正常显示占位，不报错。

## 7. 备注（含默认假设，如需调整请在 PR 指出）
- 只读 / 编辑的切换沿用 **REQ-005**（信息清单默认只读、点「编辑」才可改）—— 本需求只新增「参考图」列，不改只读逻辑本身。
- 默认：点缩略图弹层看大图；每条支持多张。若只需单张或点击跳原图链接，请指出。
- 图片复用现有信息清单图片上传能力与存储位置，不新建独立图床。
