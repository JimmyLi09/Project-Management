# 需求：项目档案（按业务类型登记表）+ 项目编号

- **需求编号**：REQ-006
- **标题**：项目档案登记表（7 类）+ 新项目 NO. 编号
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-08-05
- **优先级**：P1 · 对应优化点 #4 #17

## 1. 背景
需要“项目档案”像 Google Sheet 一样按业务类型跨项目汇总登记（#4）；新加项目需自动带 NO. 编号（#17）。

## 2. 目标
总菜单「项目档案」下按业务类型分登记表：LED / Scale Model / Projector / 3D Links / MAXHUB / AV System / Others；跨项目汇总、可筛选/KPI/导出导入/新增/详情/分页；新记录自动编号。

## 3. 范围
**做：** 7 张登记表框架 + 业务专属列（Scale/Projector 沿用参考图，其余为建议列待确认）+ 自动 NO. 编号。数据同源于各项目服务包记录（见实施说明 v1）。
**不做：** 不做文件本体存储（待定，先仅信息/外链）。

## 5. 验收标准
- [ ] 「项目档案」可切换 7 类登记表，各表跨项目汇总记录。
- [ ] 每表有筛选、KPI 卡、导出/导入、新增、详情、分页。
- [ ] 新增记录自动带下一个 NO. 编号。
- [ ] 在登记表编辑某行=更新对应项目该服务记录（单一真源）。

## 7. 备注
详见《开发实施说明 v1》。5 类建议列待 PD 微调。
