## 3. 功能说明

### 3.1 01 立项（投影业务线）
新增以下输入：
- 场景：单面墙 / 沉浸式多面 / 地面 / 会议室 / 弧幕 / 投影模型；
- 是否有互动（墙面 / 地面）；
- 环境光（暗室 / 有窗 / 明亮）；
- 天花高度；
- 最近观众离墙距离。

AV-019 的「主要播放什么」也适用于投影线。

### 3.2 05 方案配置 · 投影面与融合组
- 空间拆成若干**融合组**。一个融合组 = 一段连续融合的画面，可以由多个**投影面**组成：
  - 墙：宽、高、转角°；
  - 地面：长、宽；
  - 弧面：放第二步。
- 例子：MY016 是 1 组 3 面（U 形连续）；MY014 是 2 组（两面墙各自融合）；114 是 2 组（两块区域）。
- 每组可选：投影机（设备库）、镜头（该机型可用镜头）、可用投射距离、画面离地高度。
- 单面墙 = 1 组 1 面。

### 3.3 计算（prj@0.2，每个融合组）
1. 展开宽 L = Σ 各面宽；高 H = 最高的面。
2. 单台画面宽至少要盖住高度：w_H = H × 画面比例（WUXGA 为 1.6）。
3. 台数 n = ceil((L ÷ w_H − o) ÷ (1 − o))，o 为融合带占比。之后检查照度，不够就 n + 1，直到达到目标照度。
4. 单台画面宽 w = max(L ÷ (n(1 − o) + o), w_H)；单台画面高 h = w ÷ 1.6；融合带 = o × w。
5. 照度（公司算法）= 流明 ÷ (w × h)。
6. 投射距离：镜头投射比范围 × w，取在可用距离内的值。可用距离不够时标红，提示「换短焦镜头或加台数」。
7. 镜头离地 = min(天花 − 吊装下沉, 画面中心 + 最大镜头位移 × h)；需要的镜头位移超过机器能力时标红「天花太矮」。超短焦机按画面顶 + 0.2 m 算。
8. 遮挡：最近观众位置的光线高度 = 画面底 + (镜头离地 − 画面底) × 观众离墙 ÷ 投射距离；低于人头高（1.8 m）时标黄。有互动时建议背投或超短焦。
9. 清晰度：单像素 = w ÷ 1920，应 ≤ 最近观看距离(m)。
10. 用电 = Σ 规格书功耗，回路沿用 2.5 kW 公司常量。
11. 地面：投影机吊顶向下，投射距离 = 天花 − 下沉，检查镜头是否能投出所需画面。

**样本回测**（原型实算，作为单元测试的期望值）：

### 3.4 图纸输出（05 页 + DXF + 技术方案）
1. **平面机位图**：投影面、投影机编号、投射锥、投射距离。
2. **展开立面 · 融合区**：各面展开成一条，标出每台画面范围、融合带（斜线）、转角位置和尺寸。
3. **剖面图 · 遮挡检查**：每组一张，标出天花、吊装、镜头离地、投射光线、最近观众和人头高。挡光处标红。
4. **系统示意图（Schematic diagram）**：PC 主机 → 融合软件 → 多屏宝 → HDMI 光纤线 → 各投影机；交换机 / 中控连所有设备；雷达 → 交换机 → PC（CJ-Sync 交互）。（JM 在填写表「其他」里点名要这张。）
5. **DXF**：以上 1–3 分图层输出（投影面、机位、投射锥、融合区、尺寸、遮挡检查）。
6. **技术方案（中 / 英）**：配置表、计算依据、检查结果、常见坑提示。
7. 沿用 AV-019 的做法：图层不重叠、计算依据表三处共用一份数据、可手动调整机位（拖动机位或改投射距离，标「人工调整」）。
