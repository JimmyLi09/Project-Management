# 需求：新建项目表单 — 字段可增删 + 分区 + 公司联系人

- **需求编号**：REQ-010
- **标题**：新建表单字段可增删、分区分隔、相关公司加联系人/电话/Email
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-08-06
- **优先级**：P2 · 对应 0806 建议 #1 #2 + 批注5

## 1. 背景
不是所有项目都有总包/建筑师/景观等公司；现表单一次性全列、各段无分隔，新人易填错漏填。且缺少每个公司的联系人信息。

## 2. 目标
相关公司信息按需增删；表单按「客户信息 / 相关公司 / 服务类型 / 项目属性」分区；每个公司可填 公司名 + 联系人 + 联系电话 + Email。

## 3. 范围
**做：** 相关公司块可「+添加/−删除」；分区标题分隔；每公司含 公司名/联系人/电话/Email；服务类型标签可增删。
**不做：** 不做通讯录联动（本期仅表单内录入）。

## 5. 验收标准
- [ ] 可新增/删除相关公司块，保存后持久化。
- [ ] 表单显示分区标题，各段视觉分隔。
- [ ] 每个公司可录入 公司名/联系人/电话/Email 并保存。
- [ ] 服务类型标签可增删。

见操作端效果图「新建项目表单」页。
