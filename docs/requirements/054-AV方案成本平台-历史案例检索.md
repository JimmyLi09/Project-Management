# 需求：AV 方案成本平台 · 历史案例检索

- **需求编号**：REQ-054
- **所属系统**：AV 方案成本平台（系统一）
- **状态**：已实现
- **创建日期**：2026-09-28
- **决策来源**：2026-09-28 Jimmy「『历史案例检索』也一起移植过去」，附公司《All the Project Links》统计表

## 1. 做法

移植 avcost-phase1 的 `scripts/import_cases.py` 与 `search_cases`：读取统计表的两张 LED 工作表，按关键词、点间距、面积检索。无模型、无向量，纯 SQL。

- **读取**：制图服务 `services/drawing/avdrawing/cases.py`（openpyxl 3.1.5），只读、输出 JSON；平台写入 `av_case` 表。
- **导入**：「AV 历史案例」页上传 xlsx，**整体替换**案例库（统计表是正本，案例库是它的可检索副本；重复导入不会重复或残留）。仅 PD / BD。
- **检索**：关键词（项目名 / 客户 / 地址 / 型号 / 表内编号 / 备注）、状态（进行中 / 已完成）、点间距区间、面积区间；按面积从大到小。能看价格库的角色可看（客户名与项目规模属商业信息，成员、只读看不到）。
- **不提交真实统计表**：其中有客户与联系人信息；测试夹具在 `tests/test_cases.py` 里现场生成。

## 2. 统计表的读法

| 字段 | 进行中表（列） | 已完成表（列） |
|---|---|---|
| 年份 | A | — |
| 表内编号 | — | B |
| 项目名 / 客户 / 地址 | B / C / D | C / D / E |
| 长 / 高 (mm)、面积 ㎡ | J / K / L | K / L / M |
| 模组数（Total） | O | P |
| 型号（点间距由此识别，如 P1.56 COB） | P | Q |
| 配电 kW / 电源线 / 数据线 | Q / R / S | R / S / T |
| 备注 | U | V |

MAIN CON 列（联系人与电话）不读取。

相对系统二原版的修正（用 2026-09-28 上传的统计表核对）：

1. **按行识别列位**。已完成表里约 80 行是从进行中表整行搬过来的（A 列是年份、B 列是项目名）。原版一律按完成表列位读，项目名、客户、地址错一列，地址栏读进了联系人电话，点间距、面积也读错。现按以下顺序判定：A 列是年份 → 进行中列位；否则看「长 × 高 ≈ 面积（±5%）」对得上哪种；再看本表列位下有无项目名；都判断不了则沿用上一行。
2. **多块屏的项目**。同一项目的第二、三块屏写在下一行、不再填项目名，原版跳过。现每行一块屏，续行沿用上一行的项目名、客户、地址、年份、编号。
3. 进行中表也读取年份、客户与地址。

上传的统计表：进行中 15 块屏、已完成 222 块屏，共 237 块屏、约 161 个项目；206 块屏识别出点间距（原版读法 70）。有 6 行统计表本身的长 × 高与面积不符（如 The M 9600 × 4800 记 72 ㎡），照原样导入，需在统计表里更正。
