## 1. 现状（查代码确认）
- 右侧每行只显示 `开始 → 结束`（没有就是「— → —」）和工期（`StagePanel.tsx:200-218`）。**右侧没有任何日期输入**，日期只能在左侧日历点选、拖边界、用方向键，或用 Reverse plan。
- **工期周数算错**：勾了 Exclude Holidays 后 `calculateDuration` 返回的是**工作日**，`formatDuration` 却按 7 天折算（`duration.ts:44-50`：`Math.floor((duration / 7) * 2) / 2`）。Sep 27 – Oct 11 有 10 个工作日 = 2 个工作周，结果显示「1w」。单元测试也写成了错误的预期（`formatDuration(8)` → `'1w'`）。底部 FINAL RESULT 的「3.5w」同样有问题（`StagePanel.tsx:117-121`）。
- Exclude Holidays 只影响显示，不保存（`CalendarPlanner.tsx:174`），Reverse plan 也不考虑它。
- 标题与日期重叠：`.stage-row-main` 是 `flex-wrap + align-items: baseline`，h3 带 `margin-left:-4px`，备注输入框 `.stage-note-input` 没有任何样式，挤在同一行里（`planner.css:771-840`）。

## 2. 功能说明

### 2.1 右侧显示并可选日期
- 每个阶段行固定两行：
  - 第 1 行：序号 + 阶段名（过长省略，悬停看全名）+ 工期标签。
  - 第 2 行：**开始日期 → 结束日期**两个日期选择框（点开是小日历，也可以直接输入），后面是备注框。
- 还没定项目开始日时，阶段 01 的开始日期框高亮，提示「选开始日期」。在这里选和在左侧日历点选**效果完全一样**。
- 规则（和左侧拖边界一致，保持阶段首尾相接）：
  - 改某阶段的**结束日** = 下一阶段的开始日跟着变；后面的阶段**整体顺延**（保持各自工期），可以勾「只移动这一个边界」改为只挤压下一阶段。
  - 改某阶段的**开始日** = 上一阶段的结束日跟着变。
  - 结束日早于开始日、或把下一阶段压到 0 天，不允许，并提示原因。
  - 勾了 Exclude Holidays 时，日期框里周末和公众假期置灰（仍可选，选了给提示「这天是周六」）。
- 左右**实时联动**：右边改了，左边日历色块马上变；左边拖了，右边日期框马上变。

### 2.2 工期显示修正
- 勾 Exclude Holidays：工期按工作日显示，**5 个工作日 = 1 周**。例：10 个工作日显示「2w」，7 个工作日显示「1.5w」（按 0.5 周取整）。悬停显示精确值「10 个工作日」。
- 不勾：按日历天，7 天 = 1 周（现状逻辑）。
- 底部 FINAL RESULT 同样按这个规则；同时显示「共 25 个工作日 · 5w」。
- 改正单元测试的预期值，并补用例：周日开始、周日结束、跨公众假期。
- Exclude Holidays 开关**随排期一起保存**；Reverse plan 在勾选时按工作日分配。

### 2.3 版式
- 修掉标题与日期重叠：标题单独一行，日期 + 工期 + 备注在第二行；窄屏（< 1100 px）时备注换到第三行。
- 备注框给出明确样式（与 REQ-040 的输入框一致）。
