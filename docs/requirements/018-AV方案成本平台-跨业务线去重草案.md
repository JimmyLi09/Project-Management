# 需求：AV 方案成本平台 · 跨业务线共用资源去重草案 xline@0.1-draft

- **需求编号**：REQ-018
- **标题**：跨业务线去重：共用类别标注、草案扣减规则、06 项目汇总与 07 报价
- **所属系统**：AV 方案成本平台
- **状态**：已实现（草案）；扣减比例**待校准**
- **创建日期**：2026-09-26
- **优先级**：P1 · 决策来源：2026-09-26 Jimmy「接着做跨业务线去重，按行业常规出草案规则」

## 1. 背景

原型 Summary.dc.html 在合并总报价里有一行「共用资源去重」：弱电机房机柜与 UPS（LED 控制设备并入同一机柜）、
主干桥架共用段、进场与吊装合并一次、调试人工重叠工日。去重规则「由跨包规则集定义，不在任何单一业务包内」。

## 2. 做法

**识别**：成本行带一个「共用类别」。原型里那几项（进场、桥架、调试人工）都不是各业务线公式算出来的，而是 06 的**附加项**，
名称是 PM 自由填写的，按名称猜不可靠。所以由 PM 在 06 附加项上**明确标注**；公式行里只有弱电机柜（E13）自动标为「机柜」。
服务端只接受下表四个类别，其他值丢弃。

**扣减**：某一类别在**两条及以上业务线**出现时，售价金额最大的那条业务线保留全额，其余各线的该类别行按比例扣减
（成本、售价同比例扣减）。只出现在一条业务线的类别不扣。

| 类别 | 扣减比例 | 行业常规依据 | 校准方式 |
| --- | --- | --- | --- |
| 进场与吊装 | 100% | 同一现场只进场、搭设临设、租用吊装设备一次（总包 preliminaries 按项目计） | 对照多线项目实际进场次数 |
| 机柜 | 100% | LED / 投影控制设备并入弱电机房机柜，弱电机柜已含 30% 余量；须核对 U 数 | 按实际设备 U 数 |
| 系统调试 | 20% | 多系统联调时现场配合与测试工日重叠 | 用实际调试工日反推 |
| 弱电桥架 / 线槽 | 30% | 信号线（LED 数据线、投影信号线、弱电线缆）主干路由共用 | 用实际桥架长度反推 |

**不纳入**：
- **强电与光伏线缆**：电源线、光伏直流 / 交流线缆按电气规范须与信号线分隔敷设，不与弱电桥架共用，不应标记；
- **UPS**：共用 UPS 须按合并负载重新选型，不能简单删去较小的一台，本草案不处理；
- **设计与项目管理费**：目前成本表里没有这一项。

## 3. 界面与流程

- **06 成本核算**：附加项名称下方有「共用类别」下拉（非共用 / 进场与吊装 / 机柜 / 系统调试 / 弱电桥架·线槽），
  悬停显示依据；非编辑状态和公式行显示「共用 · 机柜」等标签。保存的成本表带上标注。
- **06 项目合并汇总**：各业务线之后增加一行「共用资源去重 · xline@0.1-draft · 草案」（成本与售价均为负数），
  项目合计相应扣减；下方列出去重明细（保留哪条线、扣哪几行、比例、依据）。汇总按各线**最新成本表**计算，含草稿时仅供参考。
- **07 报价审批**：只在**所选且已确认**的业务线之间去重。计算顺序：售价合计 → 共用资源去重 → 折扣（作用于去重后的售价）
  → 不含税小计 → GST 9% → 含税总计；成本同步扣减，毛利按扣减后的成本和小计计算。
  有扣减时提示 QUOTE-XLINE：「扣减比例未经校准，请审批人核对」（提示，不阻断）。
  报价锁定当时的去重明细；客户报价单在合计与折扣之间逐行列出「跨系统共用：进场与吊装 − S$…」。
- 数据：`av_quote` 新增 `dedup` 列（旧库自动补列，旧报价视为无去重）。

## 4. 现状说明

按 REQ-017 的决定，07 只收成本已确认的业务线，而投影、弱电、光伏都是草案规则包、成本不能确认。
所以**目前 07 实际不会触发去重**，去重只在 06 项目汇总中可见；待其他业务线校准后，07 自动生效。

## 5. 验收（测试与浏览器实测）

- [x] 单元测试：只取有标注的行、金额 = 单价 × 数量；四条业务线场景——进场保留 LED 扣弱电 + 光伏、机柜保留弱电扣 LED、
      调试保留投影扣 LED 20%、只有一条线的桥架不扣；单条业务线不去重；报价中扣减先于折扣、成本同步扣减、草案提示；
      弱电机柜自动标注、附加项按标注、未标注不带字段。
- [x] 浏览器：新建 LED + 弱电项目；LED 附加项「进场与吊装」（S$3,000）、「控制机柜」（S$900），弱电附加项「进场」（S$2,000），
      弱电机柜 2 台（S$2,100）自动标注；伪造的类别被服务端丢弃。06 汇总：进场保留 LED 扣弱电 −2,000 / −1,500，
      机柜保留弱电扣 LED −900 / −600，合计扣减售价 2,900、成本 2,100，项目合计 S$71,075，与手算一致。
- [x] 07（测试库中把弱电草稿成本表直接标为已确认，仅用于验证）：预览显示两条去重与草案提示；提交后报价锁定去重明细；
      批准后报价单列出两行「跨系统共用」，不含税小计 71,075.00，含税总计 S$77,471.75（手算一致）。
