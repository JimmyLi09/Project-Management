# 需求：英文显示补全（i18n）

- **需求编号**：REQ-041
- **标题**：EN 模式补全词条、修复中英混排与文案截断
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-09-18
- **优先级**：P2 · 0917 批次

## 1. 背景
Shermin 反馈「英文显示不完善」。切到 EN 时仍有中文残留、状态枚举未译、部分长文案被截断，观感不专业、对外给客户看时尤其。

## 2. 目标
全量排查 EN 词条并补齐（表头 / 按钮 / 状态枚举 / 提示语 / 空态）；修复被截断的文案；建立中英词条对照，后续新文案同步维护。

## 3. 范围
**做：**
- **补词条**：排期(Schedule)、信息清单(Checklist)、Job Record、导出、联系人、项目档案、运营中心等页面，EN 模式下表头 / 按钮 / 标签 / **状态枚举**（已确认→Confirmed、进行中→In progress、已收到→Received、待处理→Pending 等）全部有英文。
- **修截断**：对易截断处用换行 / 省略号 + hover 全文（tooltip）；不硬截断存储值。
- **词条对照**：沉淀一份 zh/en 词条表（或 i18n 资源文件），新文案两语同增。
- **优先顺序**：先 排期 / 导出 / Job Record / Checklist（对外高频），再覆盖全平台。

**不做：** 本期不引入第三语言；不做 RTL；用户自填的业务内容（项目名 / 备注等）不自动翻译。

## 5. 验收标准
- [ ] EN 模式下，排期 / 清单 / Job Record / 导出 / 联系人 等页面无中文残留（系统文案层面）。
- [ ] 状态徽章等枚举在 EN 下显示英文。
- [ ] 长文案不被硬截断；截断处可 hover 看全文。
- [ ] 有一份可维护的 zh/en 词条来源，新增文案两语同步。
- [ ] 中文模式不受影响。

## 7. 备注（含默认假设，如需调整请在 PR 指出）
- 默认覆盖顺序：排期 / 导出 / Job Record / Checklist 优先，其余逐步补齐；若要求一次全平台，请指出。
- 用户内容不翻译（仅系统 UI 文案）。
