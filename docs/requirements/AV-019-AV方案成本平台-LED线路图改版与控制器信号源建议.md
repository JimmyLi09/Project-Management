## 2. 功能说明

### 2.1 线路图不重叠（第 1 条）
- **分区布局**，每个区域独立占位、互不覆盖：
  - ① 屏体区：箱体、箱体标注、电源链、网线；
  - ② 尺寸区：上方列宽、右侧行高、总尺寸；
  - ③ 配电区：屏体下方的配电母线、回路编号与功率，回路标注**错开排列**，不和别的文字共用一行；
  - ④ 图例区：线型 / 颜色 / 箱体种类；
  - ⑤ 说明栏：项目信息和计算结果，放在**图框右侧或最下方**单独一栏。
- 所有文字按实际字宽排版（服务端用字体度量，不再用 0.62 系数）。生成后做一次**碰撞检查**：任何两块文字或文字与线框相交，就自动下移或换行；仍然放不下就扩大图框，**不允许裁切**。
- 画布大小 = 实际内容的外框 + 边距。05 页里的图可缩放（适应宽度 / 100%），不再被面板裁掉右侧。
- **图层开关**：在 05 的图上方可以分别显示 / 隐藏「箱体编号」「箱体尺寸」「电源」「网线」「尺寸线」「说明栏」。DXF 里保持同名独立图层，方便 CAD 里开关。

### 2.2 电线有计算依据（第 2 条，含 Bug 修复）

**电源回路新算法（led@1.1）**
1. 单箱功率 = 箱宽 × 箱高（m²）× 功耗密度（W/㎡）。例：0.64 × 0.48 × 500 = **153.6 W**。混合尺寸逐只计算。
2. 总功率 = Σ 单箱功率。例：48 × 153.6 = **7372.8 W**。
3. 回路数 n = ceil(总功率 ÷ 单回路上限)。例：ceil(7372.8 ÷ 2500) = **3**。
4. 电源走线**按列竖向成链**（与图上手画一致）：第 1 列自下而上，第 2 列自上而下……（蛇形，链不断开）。按这个顺序把箱体依次分给回路，每回路负载尽量相等，**允许一列中途换回路**。
5. **逐路校核**：任何一路 > 上限，n + 1 重新分配，直到全部 ≤ 上限。例：3 路 × 16 箱 = **2457.6 W ≤ 2500 W ✓**。
   - 回路 1 = 第 1、2 列 + 第 3 列下 4 只；
   - 回路 2 = 第 3 列上 2 只 + 第 4、5 列 + 第 6 列上 2 只；
   - 回路 3 = 第 6 列下 4 只 + 第 7、8 列。
6. 每路电流 = 功率 ÷ 电压（公司参数，默认 230 V）。例：2457.6 ÷ 230 = **10.7 A**。与「电源线载流上限」（公司参数，按线径表）比较，超了标红并提示加大线径或加回路。
7. 每条箱体电源链的箱数 / 电流 ≤「箱体电源级联上限」（公司参数，按箱体规格书填；未填时提示「待填，按厂家规格」）。
8. 报价根数 = n + 1 备用（不变）。

**数据线（网线走法按项目定义，05 左侧选）**
- **每行一条**（默认，现有做法）：每行带载 = 行像素宽 × 行像素高，超过单线上限才拆。例：2048 × 192 = 393,216 ≤ 560,000 → 6 条。
- **蛇形按带载**：箱体按 S 形串接，每条用到上限前换下一条。例：单箱 256 × 192 = 49,152 px，每条最多 11 只 → 48 ÷ 11 → **5 条**。
- 图上画出每条网线经过的箱体、起点（接控制器网口 1、2……）和每条带载。
- 报价根数 = 条数 + 1 备用（不变）。

**计算依据表**（05 图下方 + 技术方案 + DXF 说明栏，三处同一份数据）：

| 项 | 公式 | 本例 |
|---|---|---|
| 单箱功率 | 0.64 × 0.48 × 500 | 153.6 W |
| 总功率 | 48 × 153.6 | 7372.8 W |
| 回路数 | ceil(7372.8 ÷ 2500)，逐路校核 | 3 路 + 1 备用 |
| 每路负载 / 电流 | 16 × 153.6 ÷ 230 V | 2457.6 W / 10.7 A ✓ |
| 线径 | 公司参数 3 × 2.5 mm²，载流上限 xx A | ✓ / 超限标红 |
| 单箱像素 | 640 ÷ 2.5 × 480 ÷ 2.5 | 256 × 192 = 49,152 |
| 网线 | 每行一条：8 × 49,152 = 393,216 ≤ 560,000 | 6 条 + 1 备用 |

每一行可以展开看用到的参数和来源（公司参数 / 规则包 / 人工调整）。

### 2.3 手动调整电线、网线（第 3 条）
- 线路图工具栏加 3 个按钮：**「调整电源回路」「调整网线」「恢复自动」**。
- **调整电源回路**：
  - 左侧出现回路色板（回路 1 / 2 / 3 /「＋ 新回路」）；
  - 选一个回路，再点或框选箱体，就把箱体划给这个回路；
  - 每路实时显示功率和电流，超上限标红，有箱体没分配时提示。
- **调整网线**：
  - 选一条网线（或「＋ 新网线」），按顺序点箱体，定义串接顺序；
  - 每条实时显示带载，超 560,000 px 标红；
  - 可以改网口编号。
- 有违规（超限 / 未分配）时可以保存为**草稿**，但**不能保存为正式版本**，提示原因。
- 人工调整存进方案配置（新字段 `led_wiring_override`：每只箱体的回路号、网线号和序号），随版本保存。图上、说明栏、计算依据表都标「**人工调整 · 谁 · 何时**」。
- DXF、技术方案、06 的电源线 / 网线根数**都按人工调整后的结果**。
- 屏体尺寸、箱体、点间距等输入改了，导致人工调整对不上时：提示「输入已变，人工调整已失效」，回到自动结果。原调整留在历史版本里，不删除。

### 2.4 标注箱体尺寸（第 4 条）
- 每只箱体中心用清楚的字号标尺寸「640 × 480」（白色或浅灰，和线色区分），编号「R1C1」放在左上角的小字里，可在图层开关里隐藏。
- 箱体种类图例：「A 640 × 480 × 48 只」；混合尺寸时用字母（A / B / C）加不同底纹区分，并逐类计数。
- 尺寸线：上方逐列宽 + 总宽 5120，右侧逐行高 + 总高 2880；边列 / 边行尺寸不同时单独标出。
- 电源线、网线沿箱体边缘或中线走，**不压箱体尺寸字**。

### PR2：网线走法 + 人工调整（电源 / 网线 / 恢复自动）

- **网线走法**
  - 05 左侧加「网线走法」：每行一条（默认）/ 蛇形按带载。存在方案里（`led_data_mode`），随版本保存。
  - BOC：每行一条 6 条 + 1，蛇形按带载 5 条 + 1，06 网线根数跟着变。
  - led@1.0 的项目这一项是灰的（1.0 按每行条数公式算），升级后可选。
  - 换走法时，网线的人工调整去掉，电源的保留。
- **人工调整**
  - 线路图上方三个按钮：「调整电源回路」「调整网线」「恢复自动」。只在 led@1.1 项目出现，1.0 项目提示先升级。
  - **调整电源回路**：出现回路色板（回路 1 / 2 / 3 /「＋ 新回路」，每路实时写功率和电流，超限标红）。选一路，点一只箱体或拖一个框，箱体就划给这一路。一路被划空就去掉，后面的往前补号。没分配的箱体画红框并提示。
  - **调整网线**：选一条（或「＋ 新网线」），按顺序点箱体定义串接先后。点到别的网线上的箱体，会从那条摘下来。每条实时写带载，超 560,000 px 标红。可以改网口编号；「清空这条，重新按顺序点」。
- **存储**
  - 新字段 `led_wiring_override` 放在方案参数里（`av_config.cfg` / 草稿），随版本保存，内容：
    - 每只箱体的回路号、网线号、序号（按 `R1C1` 编号）；
    - 网口编号；
    - 哪一半是人改的（电源 / 网线）；
    - 谁、何时；
    - 排布指纹。
  - 不加表、不加列。
- **违规只能存草稿**
  - 以下情况算违规：超单回路上限、网线超带载、有箱体没分配回路或没接网线、两条网线接同一个网口、超级联上限（填了上限以后）。
  - 违规时「保存方案到项目」和流程条「下一步」的保存都不可用，写明原因；改动照常每 1.5 秒自动存草稿。
  - 服务端也拒绝存正式版本（400）。
- **下游都按人工结果**
  - 内核按调整重算回路 / 网线，06 的电源线 / 网线根数、DXF、技术方案都用同一个结果。
  - 05 / DXF 说明栏 / 计算依据表写「人工调整 · 谁 · 何时」，计算依据表只在人改过的那几行标来源。
  - 技术方案「说明与限制」加一句「电源回路为人工调整（谁 · 何时），已逐路校核」（中 / 英）。
  - 网线起点圈写网口号。
- **失效**
  - 屏体尺寸、箱体库、主力箱体等改了，排布指纹对不上时，提示「输入已变，人工调整已失效，已回到自动结果；原调整留在历史版本里」，并去掉这份调整。新存的版本不带它，旧版本里原样保留。
  - 只改功耗参数、排布没变时，调整照旧有效，重新逐路校核。
- **测试**
  - 单元测试 9 个：BOC 2 只从回路 1 改到回路 3 → 14 / 16 / 18 只、回路 3 2764.8 W 超限只能存草稿；改到新回路 4 → 合规，06 电源线 5 根；回路号压缩；网线按点的先后、改网口、网口重复；网线超带载；输入变了失效；led@1.0 忽略。
  - 端到端 28 项：在 05 上真的点箱体、拖框、清空重点、改网口、改屏宽失效、恢复自动，再核对 DXF / 技术方案 / 06。
