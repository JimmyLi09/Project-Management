# 需求：Checklist 每项支持多条收料记录 + 历史（内部 / 对外）

- **需求编号**：REQ-042
- **标题**：信息清单每个文件项可多次收料，保留历史、最新置顶；分内部记录与对外清单
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-09-18
- **优先级**：P1 · 0917 批次（源：Platform improvement - Shermin 第 5、6 页）

## 1. 背景
一个文件项（如「最终 CAD + 3D 模型」）在项目周期里会**多次收到**不同版本（v01/v02/v03…），现在只能记一条、后面覆盖前面，历史丢失。Shermin 的 Document Receiving Log / Document Checklist 设计要求：每项保留**全部收料记录**，最新一条置顶，可查历史、追加。

## 2. 目标
信息清单每个文件项支持**多条收料记录**（随时间累加、不覆盖）：最新一条标为 Latest 置顶，历史倒序可查，可「追加记录」；并提供两套视图——「内部收料记录」（团队用，全部记录含路径/备注）与「对外清单」（给顾问 / 客户，仅每项最新状态）。

## 3. 范围
**做：**
- **多记录数据模型**：每个信息项（checklist item）下挂一个**收料记录列表**，每条记录含：收到日期、文件名称、来自(from)、收到方式(Email/WhatsApp/…)、保存路径(server location)、状态、备注。
- **最新置顶 + 历史**：列表按时间倒序，最上一条标 **Latest**；项头显示最新状态 / 日期。
- **追加记录**：「＋追加记录」新增一条并置顶为 Latest，旧记录进历史（**不覆盖**）；可编辑 / 删除单条记录（删除二次确认）。
- **两套视图**：
  - **内部收料记录**（Document Receiving Log）：团队用，展示每项全部记录 + 路径 + 备注 + Actions；可搜索 / 按项 / 按状态 / 按日期筛选。
  - **对外清单**（External Checklist — Latest）：给顾问 / 客户，仅显示每项**最新**状态；可导出。
- **单项历史**（Item History）：点某项可看它的全部提交记录。
- 与 REQ-005（清单默认只读、点编辑才改）、REQ-024（参考图栏）兼容。

**不做：** 本期不做文件实际上传托管（仍记录文件名 + 服务器路径）；不做版本 diff / 预览。

## 5. 验收标准
- [ ] 每个信息项可有多条收料记录，追加后旧记录保留、最新置顶(Latest)。
- [ ] 项头显示最新状态 / 日期；可展开看历史（倒序）。
- [ ] 可追加 / 编辑 / 删除单条记录（删除二次确认）。
- [ ] 「内部收料记录」视图含路径 / 备注 / 筛选 / 搜索；「对外清单」仅显示每项最新、可导出。
- [ ] 点单项可看 Item History（全部提交）。
- [ ] 老数据兼容：原来的单条记录迁移为该项的第一条 Latest。

## 7. 备注（含默认假设，如需调整请在 PR 指出）
- 记录字段默认：日期 / 文件名 / 来自 / 方式 / 路径 / 状态 / 备注；如需增减（如「接收人」），请指出。
- 「对外清单」默认只给最新状态，不暴露内部备注 / 路径；导出沿用现有导出能力（并配合 REQ-017 版式修复）。
