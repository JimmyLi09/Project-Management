# 需求：排期「周期/交付时间」可编辑且时间线联动（Bug 修复）

- **需求编号**：REQ-001
- **标题**：排期周期/交付时间可改 + 时间线实时联动
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-08-05
- **优先级**：P0（Bug）· 对应优化点 #16 #18 #19

## 1. 背景
现有项目排期中：「周期」无法修改（#16）、「交付时间」无法修改（#18）；设了 3 周但下方时间线不变（#19）。属功能缺陷。

## 2. 目标
排期各阶段的「周期(周数)」「交付时间」均可编辑，修改后下方时间线/日期即时重算并反映。

## 3. 范围
**做：** 阶段周期可编辑；交付时间可编辑；改周期→时间线宽度/后续阶段起止日期即时联动；服务端持久化（走现有项目更新接口，带 version/CAS）。
**不做：** 不改阶段枚举；不引入甘特第三方库。

## 4. 详细需求
作为 PM，我想直接改某阶段的周期和项目交付时间，以便排期随实际调整，且时间线不用手动刷新。

## 5. 验收标准
- [ ] 修改任一阶段「周期」为新值并保存，下方时间线该段长度按比例变化，后续阶段起止日期顺延。
- [ ] 修改「交付时间」并保存，刷新后仍为新值（已持久化）。
- [ ] 周期改动后无需刷新页面，时间线即时更新（#19 复现不再出现）。
- [ ] 并发保存冲突时提示重读，不静默覆盖。

## 6. 边界与异常
周期为空/非数字→校验拦截并提示；交付时间早于开始日→提示不允许。

## 7. 备注
沿用 JSON 为项目真源、最小改动原则（见《开发实施方案 v2.2》）。
