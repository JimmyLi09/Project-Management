# 需求：新人培训（培训路径 + 进度追踪 + 考核）

- **需求编号**：REQ-036
- **标题**：新人培训模块——按角色的培训路径、完成进度追踪、考核小测
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-09-02
- **优先级**：P1 · 运营中心批次

## 1. 背景
新人入职后没有系统的上手路径，全靠带教口传，进度和掌握程度都看不见。希望把知识库里的资料编成有序的「培训路径」，能追踪每个新人学到哪、并通过考核确认真的掌握了。

## 2. 目标
在运营中心内提供「新人培训」：把知识库文档（REQ-035）编成**按角色的培训路径**；每个新人有**完成进度**（读到哪 / 打勾）；每个章节 / 路径可挂**考核小测**，通过才算完成；管理端能看每个新人的完成度与考核结果。

## 3. 范围
**做：**
- **培训路径**：可创建多条路径（如「新 PM 入门」「新 Sales 入门」「新 Model Maker 入门」），每条路径由若干章节 / 步骤组成，每步引用一篇知识库文档（REQ-035）或一段说明。
- **按角色分配**：把路径指派给某个新人 / 某角色；新人登录后能看到「我的培训」。
- **进度追踪**：新人逐步学习，可标记「已读 / 完成」；系统记录每人每步的完成状态与完成时间；显示整体完成百分比。
- **考核小测**：章节 / 路径末可配小测（单选 / 多选 / 判断题等），设及格线；提交后自动判分，达标才算「通过」；记录成绩与尝试次数。
- **管理视图**：总监 / PM 可看每个新人的培训进度、考核成绩、卡在哪一步。

**不做：** 本期不做证书 / 学分体系；不做视频课程托管（视频以外链 / 附件形式放文档里即可）；不做复杂题型（如编程题 / 主观题自动批改，主观题可先人工）。

## 5. 验收标准
- [ ] 可创建按角色的培训路径，每步关联知识库文档 / 说明。
- [ ] 可把路径指派给新人 / 角色；新人能在「我的培训」看到并逐步学习。
- [ ] 进度可追踪：每步可标完成，显示完成百分比与时间。
- [ ] 章节 / 路径可挂小测，自动判分、有及格线，达标才算通过，记录成绩。
- [ ] 管理端能看每个新人的完成度与考核结果。
- [ ] 培训内容随知识库文档更新而更新（引用同一份文档）。

## 7. 备注（含默认假设，如需调整请在 PR 指出）
- 培训内容**以 REQ-035 知识库文档为载体**：改文档即改培训材料，避免两处维护。
- 小测题库默认由 总监 / PM 维护；题型默认单选 / 多选 / 判断；是否需要填空 / 排序等，请指出。
- 「通过」默认＝完成所有步骤 + 考核达及格线；及格线默认可按路径配置（如 80%）。
- 是否要在 KPI（REQ-037）里体现「新人培训完成度」，本期先不挂钩；如需要，后续把它作为一个可选维度接进去。
