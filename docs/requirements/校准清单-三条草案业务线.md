# 校准清单 · 投影 / 弱电 / 光伏三条草案业务线

- **用途**：把 `prj@0.1-draft`、`elv@0.1-draft`、`pv@0.1-draft` 三个草案规则包的常量换成公司实际值。
- **状态**：等 Jimmy 填（2026-09-29 说本周给）。
- **填完之后**：我按填回的值发新版本 `prj@1.0` / `elv@1.0` / `pv@1.0`，`calibrated` 置 `true`，这三条线才解锁「导出正式文件」和「确认正式成本」。
- **规则包是按版本冻结的**：发新版只影响此后新立项的项目，已经在跑的项目仍按它立项时绑定的版本算，不会被改动。

## 怎么填

- **只填「公司实际值」那一列**，不用管公式。没把握的留空，我按草案值保留并继续标为待校准。
- **每条最好附一句依据**（哪个项目、哪份报价、哪个供应商规格书）。依据会写进规则包的注释，以后有人问「这个 0.85 哪来的」翻得到。
- **拿不准的可以给区间**（如「0.75–0.85，通常 0.8」），我取常用值并把区间记进注释。
- 不需要一次填完。**先填哪条线，哪条线就先解锁**，三条互不影响。

1. 收到值 → 每条线建一个新版本（`prj@1.0` 等），**不改草案包**，老项目原样。

5. 需求文档 AV-005 / 006 / 007 的状态栏从「草案，待校准」改掉。
