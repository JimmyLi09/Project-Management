## 1. 现状（查代码确认）
- 代码在 `src/lib/kb.ts`、`src/server/kb.ts`、`src/components/views/KnowledgeView.tsx`、`src/app/api/kb/files/[fid]/route.ts`。
- **附件只能下载**：`GET /api/kb/files/[fid]` 固定返回 `Content-Disposition: attachment`。附件以 base64 存在 `kb_files`，单个上限 8MB。
- **分类只有一套**：`KB_CATEGORIES` 6 项（role / business / process / policy / training / other）。
- **权限**：`canEditKb = isFull(u) || u.role === 'pm'`（PM 能改、能删任何附件）；`canDeleteKb = isFull(u)`。`canEditTraining` 直接等于 `canEditKb`。

## 2. 功能说明

### 2.1 文档按「业务 × 板块」归类
**业务（9 个）**，和流程地图的标签一致，另加「其他业务」：

| key | 名称 | 对应平台里的业务（`SVC`） |
|---|---|---|
| `overview` | 总览 / 通用 | 不分业务的制度、模板、培训 |
| `persp` | 效果图 | `cgi` |
| `anim` | 动画 | `ani` |
| `model` | 实体模型 | `scale`、`unitmodel` |
| `digital` | VR · 720 · 360 · AR | `vrar`、`matterport` |
| `saleskit` | Sales Kit APP | `saleskit` |
| `led` | LED · 投影 · MAXHUB | `led`、`projector`、`maxhub`、`tv` |
| `control` | 中控 | `av`、`elv` |
| `other` | 其他业务 | `website`、`drone`、`brochure`、`video`、`interior`、`renovation`、`lightbox`、`pv`、`others` |

- 这张对照表放在一个公共文件里（建议 `src/lib/bizMap.ts`，导出 `KB_BIZ`、`bizOfSvc(svc)`）。REQ-062 的能力矩阵和派项目限制也用它。

**板块（A – I）**，和流程地图的章节一致：

| 板块 | 名称 | 放在哪里 |
|---|---|---|
| A | 成员架构 | 只在总览 |
| B | 交接 + 制作流程 | 总览 + 每个业务 |
| C | 清单 · 排期 · 阶段准备 | 总览 + 每个业务 |
| D | 关键节点 + 总结邮件 | 总览 + 每个业务 |
| E | 会议 + 项目复盘 | 只在总览 |
| F | 邮件模板 + 项目规范 | 只在总览 |
| G | 员工培训 | 只在总览 |
| H | 新技术 / 信息收集 | 只在总览 |
| I | 改进方案 | 只在总览 |

- 业务不是「总览」时，板块只能选 B / C / D。后端同样校验。
- **原来的 6 个分类保留**，改叫「原分类」，变成列表右上角的一个筛选。新建文档时原分类不必选，默认「其他」。
- **老文档**：业务、板块为空，进「未归类」。PD / BD 逐篇归进去。**一篇都不删、不改正文。**
- **文档列表页**（原型 ②）：
  - 左边业务列表，带每个业务的文档数；最下面「未归类」。
  - 上面板块筛选条（A – I，带数量），随所选业务只显示可用的板块。
  - 搜索、原分类筛选、导入文件、新建文档。
  - 每篇文档显示业务、板块、原分类三个标签和附件数。
- **板块清单页**（原型 ③）：上面两张表原样做成一个只读说明页，所有人可看。

### 2.2 流程地图作知识库首页
- 打开「知识库」先看到流程地图（原型 ①），原样嵌入，地图自己的切换业务、展开邮件模板、调排期等交互都保留。
- 地图上方一条业务栏：点业务 = 切换地图里对应的标签；右边「这个业务的全部文档 →」跳到文档列表并带上业务筛选。
- 地图里每个板块标题（`id="sec-A"` … `sec-I` 的元素）右边加「📄 文档 n」，点一下跳到文档列表，带上当前业务和这个板块的筛选。
- **更新地图**：只有 PD / BD。上传一个新的 `.html`（上限 2MB），旧版本进版本历史，可以恢复。保留最近 10 版。
- **首次上线**：库里还没有地图时，自动把 `docs/requirements/assets/061-Audax业务流程地图_SOPMap_v5.html` 导入成第一版（归「总览 / 通用」，文档名「Audax 业务流程地图（SOP Map v5）」）。
- **安全（必须做到）**：
  - 地图是用户上传的 HTML，**不能和平台同源运行**。用 `<iframe sandbox="allow-scripts allow-popups">`，不给 `allow-same-origin`。
  - 提供地图内容的接口加响应头 `Content-Security-Policy: sandbox allow-scripts allow-popups`，这样单独打开这个地址也拿不到登录 cookie。
  - 「📄 文档 n」和业务切换通过 `postMessage` 实现：服务端在返回地图时附加一小段脚本，负责画按钮、上报点击、接收切换业务的消息；父页面只接受来自这个 iframe 的消息，并校验消息格式。
  - 新地图里找不到 `sec-X` 这些 id 时：不报错，只是不显示「📄 文档 n」，上方业务栏照常可用。

### 2.3 附件在线预览（全屏阅读器）
- **点附件名 = 打开全屏阅读器**（原型：预览 v1），不再直接下载。阅读器右上角保留「下载」按钮。
- 阅读器功能：
  - 顶栏：关闭、文件名、大小、页码（上一页 / 下一页 / 跳页）、缩放（＋ / － / 适合宽度）、下载。
  - 左侧缩略图栏，可收起。
  - 同一篇文档有多个附件时，可以「上一个附件 / 下一个附件」。
  - 键盘：← → 翻页，Esc 关闭。
- **各类文件怎么看**：

  | 文件 | 处理 |
  |---|---|
  | PDF | 直接看 |
  | 图片（png / jpg / gif / webp） | 直接看，可缩放 |
  | Word / Excel / PPT（doc、docx、xls、xlsx、ppt、pptx） | 服务器用 LibreOffice 转成 PDF 后看 |
  | 文本（txt / md / csv） | 纯文本显示 |
  | 其他（zip、dwg、视频等） | 显示「这种文件不能在线看」和下载按钮 |

- **Office 转 PDF**：
  - 上传时放进队列，**一次只转一个**，单个超时 60 秒。临时文件用完即删。
  - 转好的 PDF 另存（建议新表 `kb_previews`：附件 id、状态 `pending / ok / failed / unsupported`、PDF 内容、页数、错误信息、时间）。原文件不动。
  - 阅读器里的状态：「正在生成预览…」（自动刷新）、「已转成预览」、「预览生成失败，可以下载查看」（PD / BD 有「重试」）。
  - **已有的旧附件**：第一次被打开时再转；PD / BD 另有一个「生成全部预览」按钮。
  - `soffice` 路径：先读环境变量 `SOFFICE_PATH`，没有就试 `C:\Program Files\LibreOffice\program\soffice.exe`。
  - **服务器没装 LibreOffice 时**：Office 文件显示「服务器还没装预览组件，可以下载查看」，其他类型照常，**页面不能报错**。
- **PDF 渲染**：用 `pdfjs-dist`，**随项目打包，不走外网 CDN**（服务器在局域网）。
- **接口与安全**：
  - `GET /api/kb/files/[fid]` 保持现在的下载行为。
  - 新增预览接口（建议 `/api/kb/files/[fid]/preview`）：返回原 PDF、转好的 PDF 或图片，`Content-Disposition: inline`，加 `X-Content-Type-Options: nosniff`。
  - **只有 `application/pdf` 和上面 4 种图片可以 inline**。HTML、SVG 一律不 inline。
  - 预览和下载一样，登录用户都能看。
- 文档正文（Markdown）本来就在线显示，不变。

### 2.4 权限（原型 ④）

| 操作 | PD / BD | PM | 其他角色 |
|---|---|---|---|
| 在线阅读文档、预览附件、下载 | ✓ | ✓ | ✓ |
| 新建文档 / 导入文件 | ✓ | ✓ | — |
| 给文档添加附件 | ✓ | ✓（任何文档） | — |
| 编辑文档 | ✓ | 只能改自己建的 | — |
| 删除文档 | ✓ | — | — |
| 删除附件 | ✓ | 只能删自己上传的 | — |
| 改归类（业务 / 板块 / 原分类） | ✓ | 自己建的文档 | — |
| 更新流程地图 | ✓ | — | — |
| 看版本历史 | ✓ | ✓ | ✓ |
| 恢复旧版本 | ✓ | — | — |

- 附件要记**上传人**。旧附件没有上传人的留空，留空的只有 PD / BD 能删。
- 前端按钮和后端接口**两边都要限制**。
- `canEditTraining` 现在等于 `canEditKb`，这次把两者拆开：培训的维护权限保持「PD / BD / PM」不变，具体由 REQ-062 再定。

### 2.5 数据
- `kb_docs` 加两列 `biz`、`sec`（可空）；`kb_files` 加 `uploaded_by`（可空）；新表 `kb_previews`；地图版本的存放方式由开发决定（可复用 `kb_versions`）。
- **只加列、加表，不改不删旧数据**，启动时自动补。按惯例提供回滚脚本 `scripts/req061-rollback`（删新表、新列的数据不影响旧功能）。

### 2.6 不做
- 附件 8MB 上限不变。
- 不做在线编辑 Office 文件。
- 不做全文检索附件内容（搜索仍是标题、正文、标签）。

## 3. 上线步骤（写进上线单）
1. 服务器安装 **LibreOffice**（Windows 版，默认路径）。装完在 PowerShell 里执行 `& "C:\Program Files\LibreOffice\program\soffice.exe" --version` 能看到版本号。
2. `update.bat` 更新平台。
3. PD / BD 登录，打开知识库：确认首页是流程地图；上传一个 Word 测试预览。
4. PD / BD 把「未归类」里的老文档逐篇归进业务和板块。

## 4. 验收标准
- [ ] 打开知识库，首页是流程地图；点地图上方的「动画」，地图切到动画；点「B 交接 + 制作流程」旁的「📄 文档 n」，跳到文档列表且筛选为「动画 × B」。
- [ ] 文档列表：左边 9 个业务加「未归类」，数量正确；选「效果图」时板块只有 B / C / D；原分类筛选可用。
- [ ] 升级后老文档全部还在，都在「未归类」，正文和附件没有变化。
- [ ] 新建文档：业务选「动画」、板块选「A」时保存被拒（前端不可选，直接调接口也被拒）。
- [ ] 点 PDF 附件：弹出全屏阅读器，缩略图、翻页、缩放、下载可用；Esc 关闭。
- [ ] 上传 docx / xlsx / pptx 各一个：先显示「正在生成预览」，之后可以在线看；下载得到的仍是原文件。
- [ ] 上传 zip：显示「这种文件不能在线看」和下载按钮。
- [ ] 停掉或改错 `SOFFICE_PATH` 后：Office 附件显示「服务器还没装预览组件」，PDF 和图片照常，页面不报错。
- [ ] 断开外网后 PDF 仍能预览（pdf.js 是本地打包的）。
- [ ] 预览接口请求一个 HTML 或 SVG 附件：不会以 inline 返回。
- [ ] 以 PM（Skye）登录：
  - 能新建文档、给任何文档加附件；
  - 自己建的文档有「编辑」，别人的没有；
  - 自己上传的附件有「删除」，别人上传的没有；
  - 没有「删除文档」「更新地图」；
  - 直接调对应接口同样返回 403。
- [ ] 以 Sales / Engineer 登录：只能看和下载，没有任何编辑入口。
- [ ] PD 更新地图后，首页显示新地图；版本历史里能恢复上一版。
- [ ] 地图 iframe 带 sandbox；在地图 HTML 里读 `document.cookie` 或访问 `parent.document` 拿不到平台的内容。
- [ ] 所有新文案中英两套。
