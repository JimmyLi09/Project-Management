## 2. 功能说明

### 2.1 文档按「业务 × 板块」归类
**业务（9 个）**，和流程地图的标签一致，另加「其他业务」：

| key | 名称 | 对应平台里的业务（`SVC`） |
|---|---|---|
| `overview` | 总览 / 通用 | 不分业务的制度、模板、培训 |
| `persp` | 效果图 | `cgi` |
| `anim` | 动画 | `ani` |
| `model` | 实体模型 | `scale`、`unitmodel` |
| `digital` | VR · 720 · 360 · AR | `vrar`、`matterport` |
| `saleskit` | Sales Kit APP | `saleskit` |
| `led` | LED · 投影 · MAXHUB | `led`、`projector`、`maxhub`、`tv` |
| `control` | 中控 | `av`、`elv` |
| `other` | 其他业务 | `website`、`drone`、`brochure`、`video`、`interior`、`renovation`、`lightbox`、`pv`、`others` |

- 这张对照表放在一个公共文件里（建议 `src/lib/bizMap.ts`，导出 `KB_BIZ`、`bizOfSvc(svc)`）。REQ-062 的能力矩阵和派项目限制也用它。

**板块（A – I）**，和流程地图的章节一致：

| 板块 | 名称 | 放在哪里 |
|---|---|---|
| A | 成员架构 | 只在总览 |
| B | 交接 + 制作流程 | 总览 + 每个业务 |
| C | 清单 · 排期 · 阶段准备 | 总览 + 每个业务 |
| D | 关键节点 + 总结邮件 | 总览 + 每个业务 |
| E | 会议 + 项目复盘 | 只在总览 |
| F | 邮件模板 + 项目规范 | 只在总览 |
| G | 员工培训 | 只在总览 |
| H | 新技术 / 信息收集 | 只在总览 |
| I | 改进方案 | 只在总览 |

- 业务不是「总览」时，板块只能选 B / C / D。后端同样校验。
- **原来的 6 个分类保留**，改叫「原分类」，变成列表右上角的一个筛选。新建文档时原分类不必选，默认「其他」。
- **老文档**：业务、板块为空，进「未归类」。PD / BD 逐篇归进去。**一篇都不删、不改正文。**
- **文档列表页**（原型 ②）：
  - 左边业务列表，带每个业务的文档数；最下面「未归类」。
  - 上面板块筛选条（A – I，带数量），随所选业务只显示可用的板块。
  - 搜索、原分类筛选、导入文件、新建文档。
  - 每篇文档显示业务、板块、原分类三个标签和附件数。
- **板块清单页**（原型 ③）：上面两张表原样做成一个只读说明页，所有人可看。

### 2.2 流程地图作知识库首页
- 打开「知识库」先看到流程地图（原型 ①），原样嵌入，地图自己的切换业务、展开邮件模板、调排期等交互都保留。
- 地图上方一条业务栏：点业务 = 切换地图里对应的标签；右边「这个业务的全部文档 →」跳到文档列表并带上业务筛选。
- 地图里每个板块标题（`id="sec-A"` … `sec-I` 的元素）右边加「📄 文档 n」，点一下跳到文档列表，带上当前业务和这个板块的筛选。
- **更新地图**：只有 PD / BD。上传一个新的 `.html`（上限 2MB），旧版本进版本历史，可以恢复。保留最近 10 版。
- **首次上线**：库里还没有地图时，自动把 `docs/requirements/assets/061-Audax业务流程地图_SOPMap_v5.html` 导入成第一版（归「总览 / 通用」，文档名「Audax 业务流程地图（SOP Map v5）」）。
- **安全（必须做到）**：
  - 地图是用户上传的 HTML，**不能和平台同源运行**。用 `<iframe sandbox="allow-scripts allow-popups">`，不给 `allow-same-origin`。
  - 提供地图内容的接口加响应头 `Content-Security-Policy: sandbox allow-scripts allow-popups`，这样单独打开这个地址也拿不到登录 cookie。
  - 「📄 文档 n」和业务切换通过 `postMessage` 实现：服务端在返回地图时附加一小段脚本，负责画按钮、上报点击、接收切换业务的消息；父页面只接受来自这个 iframe 的消息，并校验消息格式。
  - 新地图里找不到 `sec-X` 这些 id 时：不报错，只是不显示「📄 文档 n」，上方业务栏照常可用。

### 2.3 附件在线预览（全屏阅读器）
- **点附件名 = 打开全屏阅读器**（原型：预览 v1），不再直接下载。阅读器右上角保留「下载」按钮。
- 阅读器功能：
  - 顶栏：关闭、文件名、大小、页码（上一页 / 下一页 / 跳页）、缩放（＋ / － / 适合宽度）、下载。
  - 左侧缩略图栏，可收起。
  - 同一篇文档有多个附件时，可以「上一个附件 / 下一个附件」。
  - 键盘：← → 翻页，Esc 关闭。
- **各类文件怎么看**：

  | 文件 | 处理 |
  |---|---|
  | PDF | 直接看 |
  | 图片（png / jpg / gif / webp） | 直接看，可缩放 |
  | Word / Excel / PPT（doc、docx、xls、xlsx、ppt、pptx） | 服务器用 LibreOffice 转成 PDF 后看 |
  | 文本（txt / md / csv） | 纯文本显示 |
  | 其他（zip、dwg、视频等） | 显示「这种文件不能在线看」和下载按钮 |

- **Office 转 PDF**：
  - 上传时放进队列，**一次只转一个**，单个超时 60 秒。临时文件用完即删。
  - 转好的 PDF 另存（建议新表 `kb_previews`：附件 id、状态 `pending / ok / failed / unsupported`、PDF 内容、页数、错误信息、时间）。原文件不动。
  - 阅读器里的状态：「正在生成预览…」（自动刷新）、「已转成预览」、「预览生成失败，可以下载查看」（PD / BD 有「重试」）。
  - **已有的旧附件**：第一次被打开时再转；PD / BD 另有一个「生成全部预览」按钮。
  - `soffice` 路径：先读环境变量 `SOFFICE_PATH`，没有就试 `C:\Program Files\LibreOffice\program\soffice.exe`。
  - **服务器没装 LibreOffice 时**：Office 文件显示「服务器还没装预览组件，可以下载查看」，其他类型照常，**页面不能报错**。
- **PDF 渲染**：用 `pdfjs-dist`，**随项目打包，不走外网 CDN**（服务器在局域网）。
- **接口与安全**：
  - `GET /api/kb/files/[fid]` 保持现在的下载行为。
  - 新增预览接口（建议 `/api/kb/files/[fid]/preview`）：返回原 PDF、转好的 PDF 或图片，`Content-Disposition: inline`，加 `X-Content-Type-Options: nosniff`。
  - **只有 `application/pdf` 和上面 4 种图片可以 inline**。HTML、SVG 一律不 inline。
  - 预览和下载一样，登录用户都能看。
- 文档正文（Markdown）本来就在线显示，不变。

### 5.2 表结构（只加列、加表，启动时自动补，老数据不改不删）
| 表 / 列 | 说明 |
|---|---|
| `kb_docs.biz TEXT`、`kb_docs.sec TEXT` | 业务 key、板块字母；都空 = 未归类（老文档全是空的） |
| `kb_files.uploaded_by TEXT` | 上传人姓名；老附件为空 = 只有 PD / BD 能删。附件清单 JSON 里也带 `uploadedBy` |
| `kb_previews(file_id PK, status, pdf, pages, error, updated_at)` | Office 附件转好的 PDF（base64，和附件同样的存法）。`status` = `pending / ok / failed / unsupported`；原文件不动 |
| `kb_map_versions(version PK, name, html, size, at, by, note)` | 首页地图，一版一行，存一版后只留最近 10 版 |
| `meta` 的 `kb.mapDoc` | 地图文档的 id |

**地图存放方式（文档写「由开发决定」）**：单独一张 `kb_map_versions` 表存每一版的 HTML，**同时**在知识库里放一篇「Audax 业务流程地图（SOP Map v5）」文档（总览 / 通用 · 原分类「通用制度」），附件就是当前那一版的 HTML（附件清单里标 `isMap`）。这样原型 ② 里地图出现在文档列表、带「首页」标记；版本历史和恢复走地图自己的表，不和这篇文档的正文版本混在一起。每存一版：新版本号 = 最大 + 1，删掉 10 版以前的，地图文档的 HTML 附件换成这一版（普通附件不动）。恢复 = 把那一版存成新的一版（备注「恢复第 n 版」）。地图文档不能删（接口 400），它当前那个 HTML 附件也不能单独删（要换就「更新地图」）。首次启动库里还没有地图时，自动导入 `assets/061-Audax业务流程地图_SOPMap_v5.html`，作者写「系统 System」。

### 5.3 接口
| 接口 | 谁能用 | 说明 |
|---|---|---|
| `GET /api/kb`、`GET /api/kb/[id]` | 登录用户 | 每篇多 `biz`、`sec`、`isMap`；单篇多 `previews`（各附件的预览状态） |
| `POST /api/kb`、`POST /api/kb/import`、`POST /api/kb/[id]/files` | PD / BD / PM | 可带 `biz`、`sec`；组合不合法 400；附件记上传人，Office 附件排队转换 |
| `PUT /api/kb/[id]` | PD / BD；PM 只能是自己建的（`created_by`） | 别人的 403。不带 `biz` / `sec` 的老调用方不改归类 |
| `DELETE /api/kb/[id]` | PD / BD | 地图文档 400 |
| `POST /api/kb/[id]/versions`（回退） | PD / BD | PM 403 |
| `DELETE /api/kb/files/[fid]` | PD / BD；PM 只能是自己上传的 | 老附件（没有上传人）PM 403；地图当前的 HTML 400 |
| `GET /api/kb/files/[fid]` | 登录用户 | **不变**，照旧 `attachment` 下载 |
| `GET /api/kb/files/[fid]/preview` | 登录用户 | PDF、png / jpg / jpeg / gif / webp 原文件 inline；Office 转好的 PDF inline；其余（HTML、SVG、还没转好的 Office…）415 JSON，不 inline。都带 `X-Content-Type-Options: nosniff` |
| `GET /api/kb/files/[fid]/preview?info=1` | 登录用户 | JSON：类型、状态（`ready / pending / failed / nosoffice / unsupported`）、页数、错误；文本文件带内容（前 512KB）。老 Office 附件第一次问到时排队转换 |
| `POST /api/kb/files/[fid]/preview`（重试） | PD / BD | 不是 Office 400，没装 LibreOffice 409 |
| `GET / POST /api/kb/previews` | GET 登录用户（是否装了 LibreOffice）；POST PD / BD | POST = 「生成全部预览」：没转好的 Office 附件全部排队（失败过的也重来），没装 409 |
| `GET /api/kb/map`、`POST /api/kb/map`、`POST /api/kb/map/restore` | GET 登录用户；POST PD / BD | 上传只收 `.html`、2MB 以内，名字取文件名 |
| `GET /api/kb/map/html?v=` | 登录用户 | 地图 HTML + 桥脚本，响应头 `Content-Security-Policy: sandbox allow-scripts allow-popups`、`nosniff`、`no-store`、`Referrer-Policy: no-referrer` |
| `GET /api/kb/pdfjs/{cmaps,standard_fonts}/[name]` | 登录用户 | pdf.js 的字符映射表和标准字体，直接从项目自带的 `node_modules/pdfjs-dist` 读（中文没嵌字体的 PDF 要用），只认这两个目录和简单文件名 |

### 5.4 首页地图和安全
- iframe `sandbox="allow-scripts allow-popups"`，没有 `allow-same-origin`：地图跑在 `null` 源里，读 `document.cookie` 报 SecurityError、碰 `parent.document` 报 SecurityError、`fetch('/api/kb')` 拿不到数据（登录 cookie 是 `SameSite=Lax`，也不会带过去）。单独打开 `/api/kb/map/html` 时由 CSP 的 `sandbox` 起同样作用。
- 桥脚本（服务端插在地图最后一个 `</body>` 前）：在 `id="sec-A"` … `"sec-I"` 的元素里画「📄 文档 n」，数字由父页面发过来；点了发 `{type:'audax-kb:docs', biz, sec}`；收到 `audax-kb:biz` 改地图的 `#hash`（地图自己按 hash 切标签）；地图里切标签发 `audax-kb:biz-changed`。父页面只认 `e.source === iframe.contentWindow` 的消息，并校验 `type` 和 biz / sec 是否在表里。脚本只用 DOM API，不用 eval。
- 「其他业务」在地图上没有标签：业务栏选它时地图停在「总览」。新地图里没有 `#tabs` 或 `sec-X`：不画按钮、不报错，业务栏照常可用（e2e 用一个空白地图测过）。
- SOP Map v5 自己引用了 Google Fonts，按「原样使用」没改；断网时浏览器用本机字体，地图照常能用。

### 5.5 在线预览
- `pdfjs-dist` **4.10.38**（固定版本，Apache-2.0），用 legacy 构建，worker 由 webpack 打包成 `/_next/static/media/pdf.worker.min.*.mjs`；构建产物里没有任何外网地址。`isEvalSupported: false`。
- 阅读器：缩略图栏（可收起）、连续滚动、看到哪页画哪页、按屏幕像素比画清楚；翻页 / 跳页 / 缩放（30% – 400%）/ 适合宽度；上一个 / 下一个附件；←→ 翻页、Esc 关闭；右上角「下载」= 原来的下载地址。
- LibreOffice：路径先读 `SOFFICE_PATH`，没有就用 `C:\Program Files\LibreOffice\program\soffice.exe`；文件不存在 = 没装：不排队，阅读器写「服务器还没装预览组件，可以下载查看」，「生成全部预览」提示 409。转换时每个文件在系统临时目录建一个空目录（含独立的 LibreOffice 配置目录，不和服务器上开着的 LibreOffice 抢），`--headless --convert-to pdf`，一次一个，60 秒超时（超时强杀），`finally` 里删目录。服务重启后还在 `pending` 的，第一次有人用到预览时重新排队。
