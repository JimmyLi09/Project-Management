# 需求：团队负载卡片去掉「工作量」进度条

- **需求编号**：REQ-029
- **标题**：团队负载卡片移除工作量百分比进度条
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-09-02
- **优先级**：P2 · 0902 批次

## 1. 背景
「团队负载」页每个人的卡片顶部有一条「工作量 100% / 80%」的进度条。这个数值口径不准、也容易误导（100% 不代表真的满载），实际参考价值低。用户要求去掉这条。

## 2. 目标
去掉团队负载卡片上的「工作量 %」进度条（含百分比数字与颜色条），其余信息保留。

## 3. 范围
**做：**
- 移除每张成员卡片顶部的「工作量」标签 + 百分比 + 进度条（图1 红叉标注处）。
- 保留卡片其它内容：头像 / 姓名 / 角色、状态标签（较满 / 可用）、进行中项目数 / 未完成任务数 / 积分、参与项目列表、转交等按钮，全部照旧。

**不做：** 不删除「团队负载」页面本身（页面和左侧导航入口都保留）；不改成员的其它统计；不动后端负载计算逻辑（只是前端不再展示这条进度条）。

## 5. 验收标准
- [ ] 团队负载页每张卡片都不再显示「工作量 %」进度条与百分比。
- [ ] 卡片其余内容（状态标签、项目/任务/积分数字、参与项目列表、转交按钮）正常显示、功能不变。
- [ ] 「团队负载」页面与左侧导航入口仍在。
- [ ] 页面不因去掉该元素而出现空白错位（间距收拢干净）。

## 7. 备注（含默认假设，如需调整请在 PR 指出）
- 本需求确认为「只去掉工作量进度条」，不是去掉整个团队负载页。
- 卡片右上角的状态标签（较满 / 可用）如果也是基于工作量算的，本期保留该标签、只去进度条；若你也想一并去掉状态标签，请指出。
