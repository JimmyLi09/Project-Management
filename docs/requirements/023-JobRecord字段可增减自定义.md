# 需求：Job Record 每个 service 资料卡字段可增减 / 自定义

- **需求编号**：REQ-023
- **标题**：Job Record 每个 service 资料卡字段增减自定义
- **所属系统**：Project-Management
- **状态**：已开发（2026-08-11 合入 main，PR #7）
- **创建日期**：2026-08-11
- **优先级**：P2 · 0811 批次

## 1. 背景
Job Record 里每个 service（沙盘模型 / LED / CGI 静帧 / Sales Kit …）的资料卡字段是写死的（状态 / Project detail / Client Contact / Model Maker / Handover Date / Expiration Date）。不同服务、不同项目要记录的信息不一样，现在缺的字段加不了、用不到的删不掉，很不灵活。

## 2. 目标
每个 service 资料卡支持「增减字段」：新增自定义字段（名称 + 类型）、删除字段、拖动排序，保存后生效。

## 3. 范围
**做：**
- 每个 service 资料卡右上新增「增减字段」入口，点开进入编辑字段态。
- 新增自定义字段：字段名（中 / 英）+ 类型（文本 / 日期 / 下拉 / 数字）；下拉类型可配选项。
- 删除字段、拖动排序，均持久化。
- 作用范围：按 **服务类型** 生效，与「项目档案」登记表同源 —— 改一次，该服务类型下所有项目的 Job Record 一致。

**不做：** 不做跨服务类型共享的全局字段库；不做字段级读写权限；不做字段公式 / 联动计算。

## 5. 验收标准
- [ ] 每个 service 资料卡都有「增减字段」入口，进入后可编辑字段。
- [ ] 可添加自定义字段（名称 + 类型：文本 / 日期 / 下拉 / 数字），保存后在该服务类型所有项目的 Job Record 中出现。
- [ ] 可删除字段、拖动排序，保存并刷新后保持。
- [ ] 与「项目档案」登记表同源：任一处改动即时一致。
- [ ] 老数据不丢：已填字段的值保留。

## 7. 备注（含默认假设，如需调整请在 PR 指出）
- **作用范围**默认「按服务类型」（与项目档案同源）。若要改成「按单个项目各自加」，请指出。
- **内置字段**（状态 / 交付日期等）本期允许删除 / 隐藏与排序；删除同源字段时二次确认（会影响项目档案）。若只允许删自定义字段、内置字段锁定，请指出。
- **字段类型**先支持 文本 / 日期 / 下拉 / 数字。
- 建议实现：字段定义（key / label / type / options / order）存在服务类型的字段 schema 上，字段值仍挂在各项目 Job Record；与项目档案登记表读写同一份 schema。
