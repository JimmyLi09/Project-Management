# 需求：知识库 / 运营中心（可持续更新的文档中心 · 含导入 / 导出）

- **需求编号**：REQ-035
- **标题**：新增「运营中心 · 知识库」——版本化文档中心（独立中心 + 内嵌流程 + 导入 / 导出）
- **所属系统**：Project-Management
- **状态**：已确认
- **创建日期**：2026-09-02
- **优先级**：P1 · 运营中心批次（培训 / KPI 的地基）

## 1. 背景
公司的培训资料、SOP、各业务做法标准、KPI 说明，现在散在个人脑子里和零散文件里，新人上手慢、标准不统一，也没有一个能「不断优化 / 新增」的地方。需要平台内有一个专门的文档中心：能新增、能改、有版本记录、能把已有文件导入、也能导出，作为「新人培训」「KPI 标准」的统一底座。

## 2. 目标
新增「运营中心 · 知识库」模块：文档可新增 / 编辑 / 分类 / 搜索，**每次修改留版本记录、可回看可回退**；能在独立中心集中浏览，也能在现有流程（服务类型 / 工作流阶段 / 项目档案）就地调出；支持把已有文件**导入**、把文档**导出**。

## 3. 范围
**做：**
- **独立模块**：左侧导航新增「运营中心 / 知识库」入口，集中管理所有文档。
- **文档编辑**：富文本（标题 / 段落 / 列表 / 表格 / 图片 / 附件），可持续编辑；中英内容。
- **版本化（核心）**：每次保存生成版本，记录 谁 / 何时 / 改动摘要；可查看历史、对比、回退。
- **分类与检索**：分类（按角色 / 按业务 / 按流程环节 / 通用制度）+ 标签 + 关键词搜索。
- **内嵌调用**：文档可关联到「服务类型」「工作流阶段」「项目档案」等锚点，在这些位置就地打开。
- **导入**：上传已有文件（.docx / .pdf / .xlsx / 图片，可多选）生成文档；每个文件可选「解析为正文」或「作为附件」；导入时选归类。
- **导出**：单篇文档导出为 PDF / Word；可按分类批量导出。
- **权限（默认假设，见备注）**：编辑 / 新增 / 导入权限给 总监 / PM / 指定人；其他角色默认只读、可导出。

**不做：** 本期不做多人实时协同编辑；不做文档审批发布流；不做对外公开分享链接；不做扫描件 OCR。

## 5. 验收标准
- [ ] 左侧有「运营中心 / 知识库」模块，可新增 / 编辑 / 删除（删除二次确认）文档。
- [ ] 富文本 + 图片 + 附件正常展示。
- [ ] 每次修改留版本记录（谁 / 何时 / 摘要）；可看历史并回退。
- [ ] 可按分类 / 标签浏览、关键词搜索。
- [ ] 能把文档关联到「服务类型」或「工作流阶段」并就地打开。
- [ ] **导入**：可上传 .docx / .pdf / .xlsx / 图片生成文档，可选解析正文 / 作为附件、可选归类。
- [ ] **导出**：单篇可导出 PDF / Word。
- [ ] 权限生效：无编辑权限的账号只能看 / 导出、不能改。

## 7. 备注（含默认假设，如需调整请在 PR 指出）
- **权限**默认「总监 / PM 可编辑，其余只读」；更细的分配（按分类授权、某些文档仅总监可见）请指出。
- **导入解析**：默认逐个文件选「解析为正文 / 作为附件」；若要整批默认作为附件、再手动整理，请指出。
- **版本回退**默认整篇回退；不做段落级部分回退。
- 本条是 **REQ-036（新人培训）**、**REQ-037（KPI 看板）**、**REQ-038（积分标准）** 的底座：培训资料、KPI / 积分标准说明都以本模块文档为载体。
- 与已上线 **REQ-006 项目档案** 不同：项目档案按项目 / 客户登记；本模块是公司级知识 / 制度 / SOP，可互相链接不合并。
