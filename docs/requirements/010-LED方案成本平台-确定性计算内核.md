# 需求：AV 方案成本平台 · LED 确定性计算内核

- **需求编号**：REQ-010
- **标题**：LED 业务线计算内核（参数三层模型 + 公式库 F1–F10 + 箱体排布 + 线路计算 + 校验规则 + 计算链标注）
- **所属系统**：AV 方案成本平台（本期代码置于 Project-Management，`src/av/` 可整体抽离）
- **状态**：已实现；数据线口径已裁定为逐行（2026-09-25）
- **创建日期**：2026-09-25
- **优先级**：P0 · 对应《LED 业务线开发交付规格说明书 v1.0》§3–§9、验收 A1–A6 / A8 / A9

## 1. 背景

规格书 v1.0 冻结了 LED 业务线第一期的全部字段、公式与常量。其中 §1 的设计原则要求：
AI 只负责图纸信息抽取与文档文字生成两头，中间的排布、功耗、线路计算全部是确定性代码，
任何情况下不得把数量、功率、回路数交给大语言模型计算。因此计算内核必须独立于界面与 AI，
可单独验收。

## 2. 目标

产出一个无框架依赖的 TypeScript 内核（`src/av/core/`），实现规格书 §3–§9，并以规格书
§6.3 的 144-Chuan Grove 实际图纸用例与 §7.3 的 9 个真实项目作为回归基准。

## 4. 关键设计决策

1. **参数分三层存储，不合并为一张配置表**（§3）。公司级电气常量、控制系统参数、屏体类型
   参数组的变化频率与责任人不同。三者与公式库一起冻结为一个「规则包」版本；项目只存版本号，
   重新打开时解析回同一份快照 —— 这是 A8 的实现方式。
2. **公式以表达式字符串存储**，由 `expr.ts` 求值。表达式语法只有四则运算、括号与
   `floor/ceil/round/min/max/abs`，没有属性访问与宿主调用，工程负责人改公式改不出可执行代码。
3. **箱体排布双轴独立求解**（§6）。宽高各自做一维完全背包 DP，第一优先「非主力规格最少」，
   第二优先「总数最少」；结果按主力在前排序，使异形箱体落在顶行与右列。**不得**简化为
   「固定一种箱体 + 余量切边」。
4. **回路分组用最小化各组功耗对均值的平方偏差**，而非最小化最大组。后者无法区分 3+3+1 与
   3+2+2（二者最大组相同），而 §6.3 要求 3+2+2。

- [x] **A3（电源线部分）** 8 个可比项目的电源线报价数全部复现 §7.3 的「算出」列，其中 5 个与

- [x] **A3（数据线部分）** 按裁定以逐行口径为准（第 6 节）；§7.3「算出」列与 A3 条文需按逐行口径修订。

- [x] **A6** 室外固装与租赁屏参数组 `calibrated = false`，`exportable = false`，但仍可试算。

## 6. 已裁定 · 规格书内部口径冲突：数据线

规格书对数据线条数给出了两套互斥口径：

- **逐行口径**：§5 的 F8 `Σ ceil(px_w × round(row_h ÷ P) ÷ data_px)`、§7.2 的详细说明、
  §6.3 的验证用例（144 的「480 高行各 1 条、640 高行 2 条」＝ 6 条）三处一致。
- **整屏口径**：§7.3 吻合度表的「算出」列，实为整屏总像素一次 ceil。

两者在多行屏上必然不同（146-OLR：整屏 39、逐行 40），而 §12 的 A3 要求「数据线复现第 7.3 节
结果」，因此 A3 按字面无法达成。

**本期实现取逐行口径**（规格三处明写，且一条数据线不跨行，取整必然发生在每一行），同时在
`npm run led:regression` 中并列输出「表内 / 逐行 / 整屏」三列留证。

另发现 §7.3 表中 128-C&K T1 与 021-Nafa 两行的数据线「算出」值与两种口径均不相符，已在
`fixtures.ts` 中标记 `docDataInconsistent`。

**裁定（2026-09-25，Jimmy）：以逐行口径为准。** F8、§7.2、§6.3 不变；规格书 §7.3 的数据线
「算出」列与 §12 A3 的数据线条文应在下一版按逐行口径修订。`npm run led:regression` 继续并列输出
整屏口径，仅作与旧记录对照之用。

## 7. 备注

- 内核无 React / Next.js / 数据库依赖，`src/av/` 整个目录可原样搬入独立的 AV 平台仓库。
- 字段前缀 `led_` 不得跨业务线复用（§4）；`BusinessLine` 已预留 `projector / elv / pv`。

  （该产品模组为 300×168.75，非参数组的 320×160），规格书字段表未列出，属实现补充。
