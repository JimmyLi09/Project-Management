## 1. 现状（查代码确认）
- **封面信息表**（`ExportOverlay.tsx` 约第 380 行 `coverMeta`）共 3 行 × 2 对，第一对是「项目编号 / Project no.」。
  - 预览封面和 REQ-055 的 Excel 封面都用这份数据。
- **排期样式**下拉（`schedStyle`）有三项：
  - `classic` 阶段表；
  - `weeks` 按服务分组（周）；
  - `dates` 按日期。
  - 没有日历 / 甘特的输出。
- **排期右侧面板**（`src/features/schedule-planner/components/StagePanel.tsx`）每个阶段**一直展开**：
  - 第 1 行：名称 + 工期徽章；
  - 第 2 行：开始 → 结束两个日期框（REQ-046）；
  - 第 3 行：备注输入框（REQ-040）；
  - 工期输入（REQ-048）；
  - 负责人 / 状态下拉（REQ-048，通过右侧附加内容传进来）。
  - 阶段一多，面板很长。现有的 `editingIndex` 只用来改阶段名。

## 2. 功能说明

### 2.1 封面去掉「Project no.」
- `coverMeta` 去掉「项目编号」那一对，其余字段不变。排成：

  | 行 | 内容 |
  |---|---|
  | 1 | Client（整行） |
  | 2 | Delivery date / Exported |
  | 3 | Services / PM |

- 预览、PDF、Excel（REQ-055）的封面同步改。
- **标题里的编号保留**：`050 · 173-Elite Park Avenue — Schedule` 不变。项目的其他地方也不变。

### 2.2 排期导出新增「月历」「甘特」
- 「排期样式」下拉加两项：**月历 Calendar**、**甘特 Gantt**。原来三项不变，默认值不变。
- 两种都是一份所选服务包一段（同现在）。选了多个服务包时，一个服务包接一个。

**月历（Calendar）**
- 每个月一页：
  - 标题「October 2026」，旁边写「Final: Oct 14 → Dec 29, 2026 · 11 weeks」；
  - 周一到周日的格子，周末浅色底。
- 每个阶段一条色条，颜色按阶段顺序。
  - 色条在阶段开始那天和每周第一天写「01 · 阶段名」。
  - 阶段开始那天左边有一条竖线。
- 节假日：
  - 格子标红，写上节日名；
  - 节假日数据和平台排期日历用同一份；
  - 平台日历勾了「Exclude Holidays」的项目照样标出来，只是提示。
- **关键日期**：每个阶段的开始日和最后交付日画小红圈。交付日写「END · Delivery」。
- 每页下面列「本月阶段 Stages this month」：色块 + 编号 + 阶段名（★ 关键节点照旧）+ 开始 → 结束 + 状态。
- 第 2 页起，页头只写「050 · 名称 — Schedule（续）」。最后一页加公司说明（勾了的话）。
- 三个显示开关，都默认勾上：「节假日」「关键日期点」「本页阶段列表」。

**甘特（Gantt）**
- 一页看完整个工期：
  - 左边两栏：阶段（编号 + 名称 + ★）、日期（如「14 Oct – 20 Oct」）；
  - 右边按周排，每格一周，从周一开始，表头写周一的日期。
- 色条按状态着色：进行中绿、未开始灰蓝、已完成灰，加图例。
- 最后一行「Delivery 交付」，在交付日画一条红线。
- 公司说明照旧放在最后。

**通用**
- 月历和甘特**固定 A4 横向**。方向按钮这时置灰，提示「月历 / 甘特固定 A4 横向」。
- 日期来源和现在的排期导出一样（`pkg.schedule` + 日历边界）。没有日期的阶段不画色条，在列表里写「—」。
- **Excel（REQ-055）不变**：排期工作表仍然是表格样式。月历 / 甘特只用于预览和 PDF。
  - 按钮旁边提示：「Excel 中排期为表格」。

### 2.3 排期右侧阶段卡片默认收起
- 每个阶段**默认只显示**：编号圈、名称、日期（`Oct 14, 2026 → Oct 20, 2026`，纯文字），右侧是「编辑」按钮和拖动把手。
- **点「编辑」后展开**，内容就是现在一直显示的那些：
  - 开始 → 结束两个日期框；
  - 备注；
  - 工期；
  - 负责人 / 状态；
  - 底部按钮「收起」和「删除阶段」。
  - 改名照旧：双击名称，或展开后改。
- **新加的阶段**（「＋ 添加阶段」或在日历上新建）**直接展开**。
- 可以同时展开多张。面板顶部加「全部展开 / 全部收起」两个小按钮。
- 展开 / 收起只是界面状态，不存库。刷新后全部收起，只有正在新建的那张例外。
- 收起时：
  - 拖动排序、左边日历选中阶段、点日历上的色条都照常可用；
  - 点日历上的某个阶段，右边对应卡片高亮，但不自动展开。
- **独立版**（没接后端、不传 `onNoteChange` 的那个）同样默认收起，展开后只有它原有的那些框。
- 「Schedule complete / Final result」区块不变。

## 4. 落地说明

- **封面**：
  - `coverMeta` 改成三行：Client 整行；Delivery date / Exported；Services / PM。
  - 预览封面和 Excel 封面（REQ-055）读的是同一份，一起变了。封面表加了 `<colgroup>`（16 / 34 / 16 / 34），Client 那格 `colSpan=3`，PDF 里的列宽和预览一样。
  - 标题里的编号、封面上方的大号编号都没动。
- **月历 / 甘特**：
  - 排版用到的数都放在新文件 `lib/schedExport.ts`，不碰 React，单元测试直接测。包括：
    - 覆盖哪几个月、每个月排哪几周（周一开始）；
    - 每周里每个阶段占哪几天，日期重叠的分到不同的行；
    - 关键日期、本月阶段；
    - 甘特的周列，以及色条、红线的位置。
  - `ExportOverlay` 加了 `CalendarBlock` / `GanttBlock`。数据和其他三种样式一样，来自 `planDates`（`pkg.schedule` + 日历边界）。阶段 = 排期里不是假日 / 节点的那些行。
  - 节假日用 `getPublicHoliday`，和平台排期日历是同一份。不管项目有没有勾「Exclude Holidays」都标出来。
  - 月历：
    - 每个月一节（`exc-month`），打印时第 2 节起从新的一页开始，并且一节不拆到两页。
    - 第 2 页起页头写「… — Schedule (cont.)」。第二个服务包也从新的一页开始，同样带这一行。
    - 色条在每一段都写「01 · 阶段名」。一个阶段跨周时，每周第一天都会再写一次。阶段开始那一段左边有 3px 竖线，颜色按阶段顺序取。
    - 关键日期是每个阶段的开始日，加上最后一个阶段的结束日（= 交付日，写「END · Delivery」）。
  - 甘特：
    - 色条按状态着色：进行中 `#2F7A57`、未开始 `#9FB2C8`、已完成 `#8B8F96`。受阻 `#C0392B` 只在有受阻阶段时才进图例。
    - 红线画在交付日那一天的中间。
  - 没有日期的阶段：月历不画色条，排在最后一页的「本月阶段」列表里，日期写「—」；甘特那一行日期写「—」，没有色条。
  - 三个显示开关（节假日 / 关键日期点 / 本页阶段列表）每次打开导出都是默认勾上，不存。
  - 选了月历 / 甘特时页面固定 A4 横向（`@page` 用横向）。方向按钮置灰并有提示，切回原来三种样式后，方向回到之前选的。
  - Excel 不变：选月历 / 甘特时，排期工作表按「阶段表」出，按钮旁边提示「Excel 中排期为表格」。
- **右侧阶段卡片**（`StagePanel`）：
  - 展开状态按阶段 id 记在界面里，不存库，刷新后全部收起。
  - 阶段列表比上次刚好多一个时（「+ 添加阶段」或在日历上新建），新的那张自动展开。
  - 收起时显示：编号圈 + 名称（完整显示，长的换行）+「Oct 14, 2026 → Oct 20, 2026」+「编辑」+ 拖动把手。
  - 展开后就是原来那些框：日期框、备注、工期、负责人 / 状态，再加底部「收起」「删除阶段」。「删除阶段」从卡片右边挪到了这里。
  - 改名：双击名称随时可以改；展开后单击也能改。
  - 拖动排序（含把手的上下键）、日历上拖 / 挪分界点都照常，收起的卡片日期跟着变。
  - 当前阶段的高亮（CURRENT）照旧跟着日历走，不会自动展开。平台日历原来就没有「点色条选中阶段」，这次没有加。
  - 独立用法（不接后端、不传 `onNoteChange`）同样默认收起。
  - REQ-057 的只读面板：按钮写「详情 / Details」，展开后只看不改，没有「删除阶段」。
- **不变**：原来三种排期样式（阶段表 / 按服务分组 / 按日期）的预览、PDF、Excel；REQ-043 权限。新文案都有中英两套。
