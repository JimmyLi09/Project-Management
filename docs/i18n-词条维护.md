# 中英词条怎么维护（REQ-041）

平台只有中文 / 英文两种界面语言，靠右上角那个 `EN / 中文` 按钮切换，选择存在浏览器
`localStorage` 的 `audax:lang` 里。下面三类东西分别走不同的地方，加新文案时照着放就行。

## 1. 一次性页面文案 —— 写 `t('中文', 'English')`

按钮、说明、空态、提示、confirm 文案都属于这一类，两语直接写在用到它的那一行：

```tsx
const { lang, t } = useLang();
<button>{t('导出', 'Export')}</button>
```

导出浮层里因为要脱离全局语言单独切换，用的是本地的 `T(zh, en)`，规矩一样。

**不要**只写中文再指望以后补 —— 补不上，这正是 REQ-041 要收拾的那一堆。
也**不要**把两种语言塞进同一个字符串（`'简单 Easy'`、`'基本信息 Basics'`），
那种写法切到 EN 之后还是半截中文。

## 2. 枚举 / 固定名词 —— 加进 `src/lib/terms.ts`

角色、难度、字段分组、联系人角色这类会在很多页面重复出现的固定名词，集中在
`src/lib/terms.ts`，一处两语，界面上用取词函数拿：

| 表 | 取词函数 | 用在 |
| --- | --- | --- |
| `ROLE_TERMS` | `roleTerm(role, lang)` | 侧栏身份、用户管理、KPI、培训 |
| `DIFF_TERMS` | `diffTerm(key, lang)` | 项目难度下拉 |
| `CONTACT_ROLE_TERMS` | `contactRoleTerm(value, lang)` | 项目联系人、通讯录 |
| `FIELD_GROUP_TERMS` | `fieldGroupTerm(group, lang)` | Job Record 字段分组标题 |
| `GATE_TERMS` | `gateTerm(value, lang)` | 排期的冻结点提示（出厂模板） |
| — | `durationTerm(value, lang)` | 典型工期（`3 周` → `3 weeks`，按规则换算） |

新增一个枚举值时两语同增。`permissions.ROLE_LABEL` 现在只是 `ROLE_TERMS` 的中文那一列，
**界面上不要直接读它** —— 直接读等于又把 EN 模式写死成中文。

库里已经存了的「中文 English」混排老值，用 `termOf()` / `splitTerm()` 在显示时劈开，
不回写数据库：历史值不该因为界面换语言被改掉。

## 3. 业务内容 —— 数据里自带两语，不做机器翻译

项目名、客户、备注这些用户自填的内容不翻译。模板带出来的生产内容在数据结构里
本来就有两语位，填模板时两边一起填：

| 内容 | 中文位 | 英文位 |
| --- | --- | --- |
| 排期任务 | `task` | `taskEn` |
| 典型工期 | `typical` | `typicalEn`（留空则按 `durationTerm` 自动换算） |
| 冻结点提示 | `gate` | `gateEn`（留空则查 `GATE_TERMS`，再查不到就沿用中文） |
| 清单栏目 | `group` | `groupEn` |
| 清单信息项 | `zh` | `en` |
| 资料卡字段 | `FieldDef.zh` | `FieldDef.en` |

`typicalEn` / `gateEn` 是 REQ-041 补的可选位。**老模板（9 列）读出来是 `undefined`，
界面自动回落，不需要迁移数据**；模板管理页面上这两列各有一个英文格，填了就以填的为准。

## 4. 「双语并排」开关

排期任务、清单信息项、模板卡片这些**内容**可以**当前语言在上、另一种语言小字压在下面**。
它不是漏翻，是刻意的：内部对着客户给的中文图纸干活，两边都看得见才好核对。
顶栏语言按钮旁边的 `中/EN` 就是这个开关，管的只有这些内容副行，**不影响界面文案**。

默认值跟着语言走：

| 语言 | 默认 | 为什么 |
| --- | --- | --- |
| 中文 | 开 | 内部干活，中英对照着看 |
| English | 关 | 给客户看的时候下面挂一行中文不像话 |

用户点过一次开关之后，选择存进 `audax:dual`（`1` / `0`），之后不再跟着语言变 ——
想回到「跟着语言走」，清掉这个键即可。代码里从 `useLang()` 取：

```tsx
const { lang, t, dual } = useLang();
…
{dual && <div className="sub">{lang === 'zh' ? it.en : it.zh}</div>}
```

对外的**导出**永远只出当前语言那一份，不受这个开关影响 —— 发给客户的文件不该并排。
