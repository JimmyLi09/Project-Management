# Audax · 项目协作台 Project Collaboration Platform

基于已验证的 Prototype v9 与《Audax Project Collaboration Platform 规划文件 v1.0》开发的**正式运行版**(Phase 1 + 部分 Phase 2):真实登录、账号角色权限(服务端强制)、多人共享数据库、完整生产工作流。

## 功能

- **登录与账号** — 每位成员使用个人账号登录;会话为签名 Cookie;所有权限在服务端校验,前端无法越权。
- **总览看板 Master Board** — 所有项目摘要(阶段进度、下一冻结点、健康状态);默认折叠,点开看完整排期;可按负责人筛选;逾期铃铛提醒。
- **项目卡片 Projects** — 卡片视图 + 新建项目(多服务可选,自动套用真实生产模板)。
- **服务包 Service Packages** — 同一项目可含 CGI / 动画 / 沙盘 / LED / 投影 / VR / Sales Kit / 单元模型等;每个服务独立的起始日、交付日、Buffer、负责人、排期与信息清单;支持「按交付日倒排」自动分配各阶段日期。
- **排期 Schedule** — 阶段、负责角色、个人指派👤、周数、计划日期、状态(未开始/进行中/受阻/完成)、冻结点★、批注;可编辑阶段/加减行。
- **信息清单 Checklist** — 分栏目信息项,状态(未收到/已收到/已确认/N/A/需修订/退回)、日期、备注、截图上传(自动压缩缩略图)。
- **我的待办 My Tasks** — PM 看自己负责项目的未完成阶段;团队成员只看被指派给自己的任务;按到期日排序,逾期标红。
- **向上汇报 Director Update** — 六个固定字段周报 + Director 决策闭环(批复/状态/日期/负责人),新鲜度提示(>7 天黄 / >14 天红)。
- **统计 Stats** — 按 PM 的项目数/进行中/积分(难度→积分),按阶段分布,逾期总数。
- **用户管理 Users** — PD/BD 创建账号、分配角色。
- **导出 Export** — 中英双语、可选栏位,打印/另存 PDF。
- **操作记录 Activity Log** — 每个项目的修改历史(操作人/时间/内容)。

## 角色权限(服务端强制)

| 角色 | 查看 | 编辑 |
| --- | --- | --- |
| PD / BD | 全部项目 | 全部内容、人员指派、难度积分、决策 |
| Sales | 全部项目 | 售前/开票收尾、商业信息;生产内容只读 |
| PM | 全部项目摘要 | 被指派项目的生产内容 |
| Member | 相关项目 / My Tasks | 仅被指派👤给自己的任务 |
| Viewer | 全部 | 只读 |

## 技术架构

- **Next.js 15 (App Router) + React 19 + TypeScript** — 前端界面完整移植已验证的 Prototype v9(信息架构与视觉不变)。
- **SQLite (better-sqlite3)** — 零配置服务端数据库(`data/audax.db`,自动创建);项目以 JSON 文档存储,用户/会话密钥独立表。
- **API 层** — 客户端所有修改以「类型化 action」提交 `PATCH /api/projects/:id`,服务端按登录身份逐条校验权限后落库,并写入操作记录 — 满足「多人同时更新不覆盖、真实用户无法越权」的正式版验收标准。
- 共享领域逻辑(`src/lib`)前后端同构:生产模板、日期推算、进度/健康/逾期计算、权限矩阵。

```
src/
├── app/            # 页面 (login, /) 与 API 路由 (auth, users, projects)
├── components/     # React 视图(看板/卡片/待办/汇报/统计/详情/导出/用户)
├── lib/            # 同构领域逻辑:类型、模板、日期与进度计算、权限
└── server/         # 仅服务端:SQLite、会话、action 权限校验
```
